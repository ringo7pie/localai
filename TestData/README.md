# TestData

モデルに解かせる試験問題と、3D 生成の入力画像を置く場所。

## 含まれるもの

| ファイル | 内容 |
|---|---|
| `数学難問-TEST.md` | 整数論・方程式などの数学難問。モデルの推論力を比べる試験 |
| `数学難問-三次元空間-TEST.md` | 三次元空間の幾何の難問（`tools/model-eval` の 3D 数学の出題の元） |

## 含まれないもの

`Chara1-*.jpg`・`Chara2-*.jpg`（3D 生成の入力画像、4 方向 × 2 体）は、出所を確かめられないため
このリポジトリに**含めない**（`.gitignore` で除外）。3D 生成（`tools/hunyuan3d`・`tools/pixal3d`）を試すときは、
**権利を持つ画像**（自分で描いた・撮った・生成した、または再利用が許されたもの）を 4 枚用意する。

- 正面・背面・左・右の 4 方向から見た同じ物体。背景は単色が望ましい。
- 全視点で物体の大きさ（縮尺）を揃える。入力の作り方と注意は `tools/pixal3d/README.md` の
  「多視点では上流が枠取りをしない」と `Documents/Hunyuan3D-2mv_使い方_4画像入力ガイド_2026-09-22.html` にある。
- ファイル名は自由。画面から 4 枚を選ぶ。置き場として `TestData/` を使うなら `.gitignore` の
  `TestData/Chara*.jpg` に合わせた名前（`Chara1-Front.jpg` など）にすると、誤ってコミットされない。
