# hunyuan3d-upstream

Hunyuan3D-2 の上流（`vendor/Hunyuan3D-2`、固定コミット f8db63096c82）を扱ううえでの事情。
毎回の運用で効く事実は `knowledge/10-silver/areas/hunyuan3d.md` にある。

## 当て物は公開版に含めない

`tools/hunyuan3d/patches/*.patch` は上流のコードの行を含む派生物で、Tencent Hunyuan 3D 2.0 Community
License は配布を EU・UK・韓国以外に限る。GitHub は地域を絞れないため、公開リポジトリと履歴には載せない
（`patches/` は `.gitignore` 済みで、手元のファイルは残る）。以下の「戻してから当て直す」「当て物を
新しく作るとき」は、手元で当て物を使う環境の話。`setup-server.sh` は `patches/` に当て物が無ければ、
当て物の工程（上流の巻き戻しと `git apply`）を飛ばす。公開版の利用者は上流を固定コミットのまま使い、
自分で当て物を作るなら `patches/` に置く。**自分で作った当て物を配布するときも同じ地域制限が掛かる。**

## 当て物は「戻してから当て直す」

`setup-server.sh` は、`patches/` に当て物があるとき、上流を固定コミットへ `git checkout -- .` で戻してから
`patches/*.patch` を番号順に当て直す。

- **1 枚ずつ `git apply --reverse --check` で「既に当たっているか」を判定する方式は使えない。**
  後の当て物が前の当て物の文脈行に重なると、前の当て物が前向きにも後ろ向きにも当たらなくなり、
  再実行が「当てられません」で失敗する。2026-09-24 に 0003 と 0004 で実際に起きた。
- 戻してから当て直せば、何度実行しても結果が同じになる。当て物が唯一の変更の源になる。
- そのため、**`vendor/` を手で編集したまま `setup-server.sh` を実行すると、その編集は消える。**
  編集は必ず当て物にしてから実行する。スクリプトは戻す前に `git diff --stat` を出して知らせる。
- 当て物を新しく作るときは、直前の当て物まで当たった状態のファイルを `/tmp` に退避し、編集後に
  `diff -u` を取る。作ったあとは「固定コミットへ戻して全部当て直した結果が、編集後のファイルと
  一致するか」を確かめる。

## 上流の引数で名前と意味がずれているもの

- **`Number of Chunks` は「分割数」ではなく「1 回に処理する点の数」。**
  `volume_decoders.py` が `for start in range(0, xyz_samples.shape[0], num_chunks)` と
  `xyz_samples[start : start + num_chunks]` で使っている。**大きいほど一度に扱う量が増えて
  VRAM を使う**ので、CUDA out of memory のときは下げる。名前から受ける印象と逆なので注意する。

## 設定ファイル（presets）

- 画面から保存した設定は `tools/hunyuan3d/presets/<名前>.json`（Pixal3D も同じ形で
  `tools/pixal3d/presets/`）。**`.gitignore` に入れず git で追跡する。** 重みや出力と違って小さく、
  利用者が作る資産のため。ただし、保存・読み込みの画面は当て物 `0005` の機能で、**公開版には無い**
  （上の「当て物は公開版に含めない」）。当て物を当てた手元の環境の話で、公開リポジトリへ push すると
  設定名がそのまま公開される。公開したくなければ `.git/info/exclude` に書いて追跡から外す。
- 設定名に使えない文字は `/ \ : * ? " < > |` と制御文字だけにしてある。許可制にすると
  「高精細（試し）」のような全角括弧の名前が通らず使いものにならない。禁止する文字は
  **Windows / SMB がファイル名に使えないもの**に合わせた。この `presets/` を Windows や SMB 共有
  （CIFS）へ置いたり git で別の PC へ持って行ったりしても、Windows で無効な名前で困らないようにするため。
- 読み込みは既定値を土台にファイルの値で上書きする。知らないキーは無視し、足りないキーは既定値、
  型や範囲が外れた値は既定値に戻して戻した項目名を画面に出す。設定項目が将来増減しても
  古いファイルが読める。
