localai

24 GB の GPU 1 枚で、ローカル AI の群れを運用し、どれが使えるかを測る。
資源の排他・推論サーバーの運用・Claude Code / Codex との連携・モデルの比較評価を、コードと計測の記録で残した個人プロジェクト。

GitHub のリポジトリ ・ 紹介ページ（docs/portfolio.md） ・ アーキテクチャ ・ NOTICE（第三者・ライセンス）

解いた問題

1 枚の GPU の取り合い

Qwen 27B だけで VRAM 22 GiB。MoE 推論・3D 生成・ComfyUI は同時に載らない。入口ページと systemd の 2 層で排他を取る。

RAM の枯渇でデスクトップごと落ちる

3D 生成の低 VRAM モードが重みを CPU 側へ置いて RAM を使い切った。メモリ上限は「物理の残りより小さく」置く。

モデルを感覚でなく測る

9 つの AI を同じ 16 問・同じ採点（隠しテスト）で比べ、速さと正しさの両方を記録した。

クラウドの AI からローカルへ回す

機械的な実装の反復だけを Qwen へ。実測では費用は減らず、役割を夜間・レビュー・ローカル完結に絞った。

能力は問ごとの点数の平均、時間は中央値。試行は 1〜3 回で、サンプリングありのため小さな差は誤差の範囲。 Claude 2 種はコーディングで全問合格し、能力では差がつかなかった（天井効果）。

調べたら、疑っていた設定が点を支えていた

Strata のコーディングの点が低いのは設定の誤りではないか、を条件を変えて調べた。評価が付けていた 思考の上限（24,576）は、点を下げる原因ではなく、支えていた。49 本のうち 45 本で上限に届いて打ち切られており、 上限を外すと公式版は 6 回とも答えが出なかった（平均 69% → 0%）。

導入する

Ubuntu 24.04・NVIDIA GPU（24 GB）・uv・systemd --user が前提です。GPU が無くても、入口ページと試験は試せます。

git clone https://github.com/ringo7pie/localai.git
cd localai
./localai doctor
./localai install portal && ./localai start portal

手順は docs/getting-started.md。 動作を確かめた構成は 1 つだけ（A30 24 GB・RAM 64 GB）で、ほかは未検証です。
