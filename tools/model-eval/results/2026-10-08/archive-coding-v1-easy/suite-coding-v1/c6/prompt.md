## 問題 C6: 辞書順で決まる位相ソート

関数 `topo_sort(graph: dict[str, list[str]]) -> list[str]` を書いてください。

- `graph[u]` のリストに `v` が入っているとき、「`u` は `v` より前に来る」という制約を表す。
- 頂点は、`graph` のキーと、どれかの値のリストに出てくる文字列の全部。
- 制約をすべて満たすように、全部の頂点を 1 回ずつ並べたリストを返す。
- 並べ方が何通りもあるときは、毎回「その時点で、自分より前に来るべき頂点がもう残っていない頂点」のうち、文字列として最も小さいもの（Python の `<` での比較）を次に置く。これで答えは 1 通りに決まる。
- 制約が循環しているとき（自分自身への制約を含む）は `ValueError` を送出する。
- 同じ制約が重ねて書かれていてもよい。`graph` を書き換えてはいけない。
- 頂点の数は最大 10,000。

例:
- `topo_sort({"b": ["a"], "c": []})` → `["b", "a", "c"]`
- `topo_sort({"x": ["y"], "y": ["x"]})` → `ValueError` を送出
