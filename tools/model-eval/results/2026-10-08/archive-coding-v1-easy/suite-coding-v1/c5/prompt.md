## 問題 C5: 四則演算の式を計算する

関数 `evaluate(expression: str) -> int | float` を書いてください。

- `expression` は次の要素からなる式。
  - 数: 0 以上の整数（`12`）か小数（`3.5`、`0.25`）。小数点の前と後ろには、それぞれ数字が 1 つ以上ある。
  - 二項演算子 `+` `-` `*` `/`。`*` と `/` は `+` と `-` より先に計算し、同じ優先順位どうしは左から計算する。`/` は普通の割り算（`7 / 2` は `3.5`）。
  - 単項のマイナス `-`。数や括弧の前に付けられ、重ねてもよい（`--3` は `3`、`2 * -3` は `-6`）。単項のプラスは無い。
  - 括弧 `(` `)`。入れ子にしてよい。
  - 半角スペース。どこに入れてもよく、無視する。ただし数の途中には入らない（`1 2` は誤り）。
- 値を数（`int` か `float`）で返す。答え合わせでは誤差 1e-9 まで許す。
- 0 で割ったときは `ZeroDivisionError` を送出する。
- 式として正しくない入力（空の文字列、括弧の不一致、演算子の過不足、知らない文字、`**` など）には `ValueError` を送出する。
- `eval`、`exec`、`compile` は使わない（使った答えは 0 点）。

例:
- `evaluate("2 * (3 + 4)")` → `14`
- `evaluate("-8 / 2")` → `-4.0`
