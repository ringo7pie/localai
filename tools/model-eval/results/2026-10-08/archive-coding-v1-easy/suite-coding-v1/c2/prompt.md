## 問題 C2: 時間の文字列を秒に直す

関数 `parse_duration(text: str) -> int` を書いてください。

- `text` は 1 個以上の「成分」からなる。成分は、0 以上の整数（半角数字 1 桁以上）のすぐ後ろに単位の文字が 1 つ付いたもの。
- 単位は `d`（日 = 86400 秒）、`h`（時 = 3600 秒）、`m`（分 = 60 秒）、`s`（秒）の 4 つで、小文字だけ。
- 成分は `d`、`h`、`m`、`s` の順に並び、同じ単位は 1 回まで。使わない単位は省いてよい。
- 成分と成分のあいだには半角スペースが 0 個以上入ってよい。文字列の先頭と末尾の半角スペースも許す。数と単位のあいだにはスペースを入れられない。
- 合計の秒数を `int` で返す。数の大きさに上限はない（`"90m"` は `5400`）。
- この形に合わない入力（空の文字列、スペースだけ、知らない単位、単位の無い数、順番の誤り、単位の重複、小数、負の数、大文字、区切りの記号など）には `ValueError` を送出する。

例:
- `parse_duration("1h 30m")` → `5400`
- `parse_duration("2d3s")` → `172803`
