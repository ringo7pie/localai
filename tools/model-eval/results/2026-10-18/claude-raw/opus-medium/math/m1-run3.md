## 考え方

T は凸多面体なので、距離 r 以下の平行体 K の体積・表面積はシュタイナーの公式（Steiner formula）で正確に求まる。

- 体積: V(r) = V0 + S0 r + (Σ_辺 L_e (π - θ_e)/2) r^2 + (4/3)π r^3
- 表面積: S(r) = S0 + 2 (Σ_辺 L_e (π - θ_e)/2) r + 4π r^2

正四面体（辺 1）:
- V0 = sqrt(2)/12
- S0 = sqrt(3)
- 二面角 θ = acos(1/3)、外角 π - θ = acos(-1/3)、辺 6 本、長さ 1
- Σ L_e (π - θ_e)/2 = 3 acos(-1/3)

r = 0.6:
- V = sqrt(2)/12 + 0.6 sqrt(3) + 3·0.36·acos(-1/3) + (4/3)π·0.216
  = 0.1178511 + 1.0392305 + 2.0634839 + 0.9047787 ≈ 4.125344
- S = sqrt(3) + 2·3·0.6·acos(-1/3) + 4π·0.36
  = 1.7320508 + 6.8782795 + 4.5238934 ≈ 13.134224

答え(a): sqrt(2)/12 + 0.6*sqrt(3) + 1.08*acos(-1/3) + 0.288*pi
答え(b): sqrt(3) + 3.6*acos(-1/3) + 1.44*pi
