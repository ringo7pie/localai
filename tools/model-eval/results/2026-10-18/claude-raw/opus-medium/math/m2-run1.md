## 考え方

A を原点にとる座標 u = x - 1, v = y, z を使う。r = 0.6 < 1 なので、V1 ∩ V2 は A の近く（|u| ≤ r, |v| ≤ r）にしかない。

- u > 0 または v < 0 の領域では、交わり V1 ∩ V2 は球 u²+v²+z² ≤ r² になる（その範囲では片方の条件が球の条件になり、もう片方より厳しい）。つまり球の 3/4。
- u ≤ 0 かつ v ≥ 0 の領域では、交わりは v²+z² ≤ r² かつ u²+z² ≤ r²（直交する 2 本の円柱の共通部分、Steinmetz 立体）の 1/4。

体積:
- 球の 3/4: π r³
- Steinmetz 立体の 1/4: (16/3 r³)/4 = 4/3 r³
- |V1| = π r² + 4/3 π r³
- |W| = π r² + (π/3 - 4/3) r³ = 0.432π - 0.288 = (54π - 36)/125

モーメント（u, v について）:
- 欠けた 1/4 球（u≤0, v≥0）: Mu = -π r⁴/8, Mv = +π r⁴/8。なので 3/4 球は Mu = +π r⁴/8, Mv = -π r⁴/8
- 1/4 Steinmetz 立体: 高さ z での断面は一辺 s = sqrt(r²-z²) の正方形。Mu = -∫ s³/2 dz = -3π r⁴/16, Mv = +3π r⁴/16
- 交わりの合計: Mu = -π r⁴/16, Mv = +π r⁴/16

V1 の重心は (0.5, 0, 0)。
- Mx(W) = 0.5·|V1| - (|V1∩V2| + Mu) = 0.324π - (0.216π + 0.288 - 0.0081π) = 0.1161π - 0.288
- My(W) = 0 - π r⁴/16 = -0.0081π

重心:
- x = (0.1161π - 0.288)/(0.432π - 0.288) = (129π - 320)/(480π - 320) ≈ 0.0717744
- y = -0.0081π/(0.432π - 0.288) = -9π/(480π - 320) ≈ -0.0238007

答え(a): (54*pi - 36)/125
答え(b): (129*pi - 320)/(480*pi - 320)
答え(c): -9*pi/(480*pi - 320)
