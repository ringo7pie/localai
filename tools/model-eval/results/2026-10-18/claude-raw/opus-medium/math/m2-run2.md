## 考え方

r = 0.6。V1 はカプセル（円柱 + 両端の半球）で、体積 = pi r^2 + (4/3) pi r^3 = 0.648 pi。重心は (0.5, 0, 0)。

V1 ∩ V2 は A の近くにしかない。u = x - 1 として、u と y の符号で 4 つに分ける。
- u ≤ 0, y ≥ 0: 直交する 2 本の円柱 y^2+z^2 ≤ r^2 と u^2+z^2 ≤ r^2 の共通部分（Steinmetz 立体）の 1/4。体積 4r^3/3
- それ以外の 3 象限: 一方が A を中心とする球で、もう一方の条件を含む。それぞれ球の 1/4 で、体積 pi r^3/3

共通部分の体積 = pi r^3 + 4r^3/3 = 0.216 pi + 0.288

モーメント（A 基準）:
- 1/4 球: u と y の重心はそれぞれ ±3r/8。u モーメントの合計 = +pi r^4/8、y モーメントの合計 = -pi r^4/8
- 1/4 Steinmetz: 高さ z の断面は一辺 a = sqrt(r^2-z^2) の正方形。y モーメント = ∫ a^3/2 dz = 3 pi r^4/16、u モーメント = -3 pi r^4/16
- 合計: u モーメント = -pi r^4/16、y モーメント = +pi r^4/16（pi r^4/16 = 0.0081 pi）

W:
- 体積 = 0.648 pi - 0.216 pi - 0.288 = 0.432 pi - 0.288 = (54 pi - 36)/125
- x モーメント = 0.324 pi - (0.216 pi + 0.288) + 0.0081 pi = 0.1161 pi - 0.288
- y モーメント = -0.0081 pi

x̄ = (129 pi - 320)/(480 pi - 320) ≈ 0.0717744
ȳ = -9 pi/(480 pi - 320) ≈ -0.0238007

答え(a): (54*pi - 36)/125
答え(b): (129*pi - 320)/(480*pi - 320)
答え(c): -9*pi/(480*pi - 320)
