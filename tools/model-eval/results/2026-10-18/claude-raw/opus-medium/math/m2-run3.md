## 考え方

座標を u = x - 1、v = y に移す（A が原点、OA は u ∈ [-1, 0]、AB は v ∈ [0, 1]）。r = 0.6 < 1 なので、V1 ∩ V2 は A の近くだけにある。

- Vol(V1) = pi r^2 * 1 + (4/3) pi r^3 = 0.648 pi。V1 の重心は (0.5, 0, 0)。

V1 ∩ V2 の分け方:
1. u > 0: 条件は A からの距離 ≤ r → 半球。体積 (2/3) pi r^3、u モーメント pi r^4/4、v モーメント 0。
2. u ≤ 0, v < 0: AB までの距離 = A からの距離 ≥ OA までの距離 → 1/4 球。体積 pi r^3/3、u・v モーメントはともに -pi r^4/8。
3. u ≤ 0, v ≥ 0: v^2+z^2 ≤ r^2 かつ u^2+z^2 ≤ r^2 → 直交円柱の共通部分の 1/4。体積 4r^3/3。高さ z の断面は一辺 s = sqrt(r^2-z^2) の正方形なので、v モーメント = ∫ s^3/2 dz = 3 pi r^4/16、u モーメント = -3 pi r^4/16。

合計: Vol(V1∩V2) = pi r^3 + 4r^3/3 = 0.216 pi + 0.288。
u モーメント = -pi r^4/16、v モーメント = +pi r^4/16（pi r^4/16 = 0.0081 pi）。

(a) Vol(W) = 0.648 pi - 0.216 pi - 0.288 = 0.432 pi - 0.288 ≈ 1.069168

(b) x モーメント = 0.324 pi - (0.216 pi + 0.288) + 0.0081 pi = 0.1161 pi - 0.288
x̄ = (1161 pi - 2880)/(4320 pi - 2880) ≈ 0.0717744

(c) y モーメント = -0.0081 pi
ȳ = -81 pi/(4320 pi - 2880) ≈ -0.0238007

答え(a): 0.432*pi - 0.288
答え(b): (1161*pi - 2880)/(4320*pi - 2880)
答え(c): -81*pi/(4320*pi - 2880)
