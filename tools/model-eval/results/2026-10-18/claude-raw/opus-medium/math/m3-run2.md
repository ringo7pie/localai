## 考え方

立方体の中心を原点に置き、立方体を [-1/2,1/2]^3 とする。面までの最小距離が d 以下 ⇔ P が内側の立方体 Q = [-a,a]^3（a = 1/2 - d）の外側にある。
球 B（半径 r = 1/2）の外側かつ Q の外側の確率は

p = 1 - (V(B) + V(Q) - V(B∩Q))

(a) d = 1/4, a = 1/4。a·sqrt(3) < 1/2 なので Q は B に含まれる。V(B∩Q) = V(Q)。
p = 1 - pi/6

(b) d = 1/10, a = 2/5。a < r < a·sqrt(2) なので、球は 6 面から互いに重ならない球冠として出る。
球冠の高さ h = 0.1、体積 pi h^2 (3r - h)/3 = 7pi/1500。
V(B∩Q) = pi/6 - 6·7pi/1500。p = 1 - 0.512 - 7pi/250 = 61/125 - 7pi/250

(c) d = 3/20, a = 7/20。a·sqrt(2) < r < a·sqrt(3) なので、球冠どうしが辺の近くで重なる（3 つの重なりは無い）。
V(B∩Q) = pi/6 - 6C + 12E。C は h = 3/20 の球冠 = 243pi/24000、E は {x>a, y>a} にある球の部分。
E = 2[(2/3) r^3 atan(z0/r) - (a/3)(3r^2 - a^2) asin(z0/c) + a^2 z0/3]（c^2 = r^2 - a^2、z0^2 = r^2 - 2a^2）
数値を入れると z0 = sqrt(2)/20, c = sqrt(51)/20 で
12E = 2 atan(sqrt(2)/10) - (1757/1000) asin(sqrt(2/51)) + 49 sqrt(2)/1000 ≈ 0.0000228258
p = 1 - 0.343 - 243pi/4000 + 12E ≈ 0.466171

答え(a): 1 - pi/6
答え(b): 61/125 - 7*pi/250
答え(c): 657/1000 - 243*pi/4000 + 2*atan(sqrt(2)/10) - (1757/1000)*asin(sqrt(2/51)) + 49*sqrt(2)/1000
