## 考え方

立方体を [-1/2, 1/2]^3 に置く。面までの最小距離が d 以下 ⇔ P が内側の立方体 |x|,|y|,|z| < a（a = 1/2 − d）に入らない。
よって p(d) = (1 − pi/6) − V(a)、V(a) = 内側の立方体のうち球（r = 1/2）の外にある体積。

### (a) d = 1/4, a = 1/4
内側の立方体の頂点までの距離は a·sqrt(3) ≈ 0.433 < 1/2 なので、内側の立方体は球にすっぽり入る。V = 0。
p = 1 − pi/6 ≈ 0.476402

### (b) d = 1/10, a = 2/5
球が面から出る部分は高さ h = 0.1 の球冠。面上の円の半径 sqrt(0.25 − 0.16) = 0.3 < a なので球冠どうしは重ならず、辺には届かない。
球冠 1 個 = pi h^2 (3r − h)/3 = 0.014·pi/3、6 個で 0.028·pi。
立方体と球の共通部分 = pi/6 − 0.028·pi、V = 0.512 − pi/6 + 0.028·pi。
p = 0.488 − 0.028·pi = 61/125 − 7·pi/250 ≈ 0.400035

### (c) d = 3/20, a = 7/20
a·sqrt(2) ≈ 0.495 < 1/2 < a·sqrt(3) なので、辺の部分も球の内側に入る（2 つの球冠が重なる）。
第 1 象限の 1/8 で包除原理を使う:
W = pi/48 − 3·(球冠の 1/4) + 3F。h = 0.15 の球冠の 1/4 = 81·pi/32000。
F = {x>a, y>a, z>0} ∩ 球の体積。断面積を積分して部分積分すると
F = atan(10·sqrt(2)/49)/24 − 1757·atan(sqrt(2)/7)/24000 + 49·sqrt(2)/24000 ≈ 9.5101e-7。
V = 8(a^3 − W) = 0.343 − 1271·pi/12000 − 24F。
p = 1 − pi/6 − V = 0.657 − 243·pi/4000 + 24F
 = 657/1000 − 243·pi/4000 + atan(10·sqrt(2)/49) − 1757·atan(sqrt(2)/7)/1000 + 49·sqrt(2)/1000
 ≈ 0.466171

答え(a): 1 - pi/6
答え(b): 61/125 - 7*pi/250
答え(c): 657/1000 - 243*pi/4000 + atan(10*sqrt(2)/49) - 1757*atan(sqrt(2)/7)/1000 + 49*sqrt(2)/1000
