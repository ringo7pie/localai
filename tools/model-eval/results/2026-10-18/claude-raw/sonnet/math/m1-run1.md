## 考え方

K は凸体 T の平行体（T と半径 r の球のミンコフスキー和）なので、シュタイナーの公式が全ての r >= 0 で成り立つ。

V(r) = V0 + S*r + M*r**2 + (4*pi/3)*r**3

- V0 = sqrt(2)/12（体積）
- S = sqrt(3)（表面積。正三角形 4 枚）
- M = (各辺の長さ x (pi - 二面角)) / 2 の総和。辺 6 本、長さ 1、二面角 acos(1/3) なので M = 3*(pi - acos(1/3))

(a) r = 0.6 を代入する。

V = sqrt(2)/12 + 0.6*sqrt(3) + 0.36*3*(pi - acos(1/3)) + (4*pi/3)*0.216
  = sqrt(2)/12 + 0.6*sqrt(3) + 1.08*(pi - acos(1/3)) + 0.288*pi
  約 4.12534

内訳: 本体 0.117851、面の厚み 1.039230、辺のまわりの円柱の一部 2.063484、頂点のまわりの球の一部 0.904779。

(b) 凸体の平行体の表面積は体積を r で微分したものに等しい。

A = dV/dr = S + 2*M*r + 4*pi*r**2
  = sqrt(3) + 3.6*(pi - acos(1/3)) + 1.44*pi
  約 13.13422

答え(a): sqrt(2)/12 + 0.6*sqrt(3) + 1.08*(pi - acos(1/3)) + 0.288*pi
答え(b): sqrt(3) + 3.6*(pi - acos(1/3)) + 1.44*pi
