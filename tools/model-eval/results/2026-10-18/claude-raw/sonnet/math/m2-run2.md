## 解法

A を原点とする座標 u = x - 1 を使う。V1 は OA のまわりのカプセル、V2 は AB のまわりのカプセル。r = 0.6 < 1 なので、V1 ∩ V2 は |u| <= r、|y| <= r の範囲に収まる。

V1 の条件: z^2 + y^2 + (max(u,0))^2 <= r^2（u >= -1 の範囲）
V2 の条件: z^2 + u^2 + (max(-y,0))^2 <= r^2（y <= 1 の範囲）

(u, y) の象限ごとに V1 ∩ V2 を調べる。

- u>=0, y>=0: 球 z^2+y^2+u^2 <= r^2 の 1/4（体積 pi r^3/3）
- u>=0, y<0: 同じく球の 1/4
- u<0, y<0: 同じく球の 1/4
- u<0, y>=0: 2 本の円柱 z^2+y^2 <= r^2 と z^2+u^2 <= r^2 の共通部分の 1/4（体積 4 r^3/3）

よって Vol(V1 ∩ V2) = pi r^3 + 4 r^3 / 3。
Vol(V1) = pi r^2 + 4 pi r^3 / 3。

### (a) 体積

Vol(W) = pi r^2 + pi r^3 / 3 - 4 r^3 / 3 = 0.432 pi - 0.288 = 1.06916803

### モーメント

V1 は x = 1/2 について対称、y = 0 について対称。
Mx(V1) = (1/2)(pi r^2 + 4 pi r^3 / 3)、My(V1) = 0。

交わり I の (u, y) モーメント（球の 1/4 の重心は各座標で 3r/8 離れる）:

- 3 つの球 1/4 の ∫u, ∫y は、それぞれ ±pi r^4/8
- 円柱の共通部分の 1/4（u<0, y>=0）は ∫y = 3 pi r^4/16、∫u = -3 pi r^4/16

合計: ∫u dV = -pi r^4/16、∫y dV = +pi r^4/16

x = 1 + u なので ∫x dV(I) = Vol(I) - pi r^4/16。

Mx(W) = Mx(V1) - Mx(I) = pi r^2/2 - pi r^3/3 - 4 r^3/3 + pi r^4/16 = 0.1161 pi - 0.288 = 0.07673891
My(W) = 0 - pi r^4/16 = -0.0081 pi = -0.02544690

検算: W を「x<0.4 の部分（円柱 + 半球）」と「残りの部分」に分けて体積と x のモーメントを足しても同じ値になった。

### (b), (c) 重心

x の重心 = 0.07673891 / 1.06916803 = 0.07177441
y の重心 = -0.02544690 / 1.06916803 = -0.02380066

答え(a): 1.06916803
答え(b): 0.07177441
答え(c): -0.02380066
