## 考え方

T は凸なので、平行体 K の体積はシュタイナーの公式が全ての r >= 0 で成り立つ。

V(K) = V + S r + M r^2 + (4 pi / 3) r^3

- V = sqrt(2)/12（体積）
- S = sqrt(3)（表面積。正三角形 4 枚）
- 辺ごとの寄与は、長さ x (pi - 二面角) / 2。二面角は acos(1/3)、辺は 6 本で長さ 1。よって M = 3 (pi - acos(1/3))
- 頂点の寄与は、各頂点の法錐が単位球面を分割するので、半径 r の球 1 個分 (4 pi / 3) r^3

r = 0.6 を代入する。

(a) V(K) = sqrt(2)/12 + 0.6 sqrt(3) + 0.36 * 3 (pi - acos(1/3)) + 0.288 pi
        = sqrt(2)/12 + 0.6 sqrt(3) + 1.368 pi - 1.08 acos(1/3)
        = 約 4.12534

(b) 凸体では表面積は dV/dr に等しい。
S(K) = S + 2 M r + 4 pi r^2
     = sqrt(3) + 3.6 (pi - acos(1/3)) + 1.44 pi
     = sqrt(3) + 5.04 pi - 3.6 acos(1/3)
     = 約 13.1342

数値の確認
- sqrt(2)/12 = 0.117851、0.6 sqrt(3) = 1.039230、1.08 (pi - acos(1/3)) = 2.063484、0.288 pi = 0.904779。合計 4.125344
- sqrt(3) = 1.732051、3.6 (pi - acos(1/3)) = 6.878280、1.44 pi = 4.523893。合計 13.134224

答え(a): sqrt(2)/12 + 0.6*sqrt(3) + 1.368*pi - 1.08*acos(1/3)
答え(b): sqrt(3) + 5.04*pi - 3.6*acos(1/3)
