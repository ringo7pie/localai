## M3 の解答

### 設定

立方体の中心を原点にして座標を [-1/2, 1/2]^3 に取る。面までの距離は 1/2 - |x_i| なので、
「最も近い面までの距離が d 以下」は max|x_i| >= s（s = 1/2 - d）と同じ。
球は半径 R = 1/2。求める体積は

p = Vol{max|x_i| >= s} - Vol{球の内側 かつ max|x_i| >= s}
  = (1 - 8 s^3) - (球のうち、内側の立方体 [-s, s]^3 の外にある部分)

球のうち内側の立方体の外にある部分は、6 枚の面ごとの球冠（高さ h = R - s）の和集合。
隣り合う面の球冠どうしは s*sqrt(2) < R のとき重なる。三つ組の重なりは s*sqrt(3) < R のときだけ空でない。
向かい合う面の球冠は重ならない。

### (a) d = 1/4, s = 1/4

内側の立方体の頂点までの距離は s*sqrt(3) = 0.433 < 1/2 なので、内側の立方体は球にすっぽり入る。
よって球の外側の点はすべて max|x_i| >= s を満たす。

p(1/4) = 1 - pi/6 = 0.4764012244

### (b) d = 1/10, s = 2/5

s*sqrt(2) = 0.566 > 1/2 なので、球冠どうしは重ならない。h = 1/10。
球冠 1 つの体積は pi h^2 (3R - h)/3 = pi * 0.01 * 1.4 / 3 = 7 pi / 1500。6 つで 7 pi / 250。

p = 1 - 8 (2/5)^3 - 7 pi / 250 = 1 - 64/125 - 7 pi/250 = 61/125 - 7 pi / 250 = 0.4000354057

### (c) d = 3/20, s = 7/20

h = 3/20。球冠 1 つは pi h^2 (3R - h)/3 = 0.010125 pi。6 つで 0.06075 pi = 243 pi / 4000。
s*sqrt(2) = 0.49497 < 1/2 なので、隣り合う 2 つの球冠が少し重なる（12 組）。三つ組の重なりはない。

W = Vol{x > s, y > s, x^2 + y^2 + z^2 <= R^2}

とすると、和集合の体積は 6 C - 12 W。

p = 1 - 8 s^3 - 6 C + 12 W = 0.657 - 0.06075 pi + 12 W

W を (x, y) 平面の極座標で積分する。t = cot(theta) と置くと

W = (4/3) s^3 * Integral_{t=1}^{T} (T^2 - t^2)^{3/2} / (1 + t^2) dt,  T^2 = (R^2 - s^2)/s^2 = 51/49

この積分は初等的に解け、k = sqrt(T^2 + 1) = 10/7 として

Integral = k^3 atan(sqrt(T^2 - 1)/k) - (k^2 + T^2/2) atan(sqrt(T^2 - 1)) + sqrt(T^2 - 1)/2
         = (1000/343) atan(sqrt(2)/10) - (251/98) atan(sqrt(2)/7) + sqrt(2)/14

したがって

12 W = 2 atan(sqrt(2)/10) - (1757/1000) atan(sqrt(2)/7) + 49 sqrt(2)/1000 = 2.2824133e-5

(atan(sqrt(2)/10) = 0.14048970175, atan(sqrt(2)/7) = 0.19934720770 を使って数値化)

p(3/20) = 657/1000 - 243 pi/4000 + 2 atan(sqrt(2)/10) - (1757/1000) atan(sqrt(2)/7) + 49 sqrt(2)/1000
        = 0.657 - 0.190851753706 + 0.000022824133
        = 0.466171070428

答え(a): 1 - pi/6
答え(b): 61/125 - 7*pi/250
答え(c): 0.466171070428
