## M3 の解答

立方体を [-1/2, 1/2]^3 に置く。点 P=(x,y,z) について M = max(|x|,|y|,|z|) とすると、最も近い面までの距離は 1/2 - M。
よって「距離が d 以下」は M >= a (a = 1/2 - d)。球は半径 R = 1/2 で、立方体にすっぽり入る(球は立方体の内側にある)。

求める確率は
p(d) = vol{M >= a} - vol(球 ∩ {M >= a}) = (1 - 8a^3) - vol(球 ∩ {M >= a})。

球 ∩ {M >= a} は、球を 6 枚の平面 |x|=a, |y|=a, |z|=a で切り落とした 6 個の球冠(キャップ)の和集合。
キャップの高さ h = R - a、体積は pi*h^2*(3R - h)/3。

### (a) d = 1/4, a = 1/4
立方体 {M < 1/4} の角までの距離は (1/4)*sqrt(3) = 0.433 < 1/2 なので、{M < 1/4} は球の内側に完全に入る。
つまり球の外側の点はすべて M >= 1/4 を満たす。よって p = 1 - (球の体積) = 1 - pi/6。

### (b) d = 1/10, a = 2/5
2 枚の隣り合う面のキャップが重なる条件は a*sqrt(2) < R。ここでは 0.4*sqrt(2) = 0.566 > 0.5 なので重ならない。
h = 1/10、キャップ 1 個 = pi*(1/100)*(3/2 - 1/10)/3 = 7*pi/1500。6 個で 7*pi/250。
vol{M >= 0.4} = 1 - 0.8^3 = 61/125。
p = 61/125 - 7*pi/250 = 0.4000354...

### (c) d = 3/20, a = 7/20
a*sqrt(2) = 0.4950 < 0.5 なので隣り合う 2 面のキャップがわずかに重なる。a*sqrt(3) = 0.606 > 0.5 なので 3 面が同時に重なることはない。
反対側の面どうしも重ならない。よって包除原理で、
vol(球 ∩ {M >= a}) = 6*(キャップ) - 12*V
(V は隣り合う 2 面のキャップの共通部分 {x>=a, y>=a, x^2+y^2+z^2<=R^2} の体積、辺は 12 本)。

- h = 3/20、キャップ 1 個 = pi*(9/400)*(3/2 - 3/20)/3 = 0.010125*pi。6 個で 0.06075*pi。
- vol{M >= 0.35} = 1 - 0.7^3 = 0.657。
- V: x を a から c = sqrt(R^2 - a^2) = sqrt(51)/20 まで動かし、各 x での (y,z) 断面は半径 s = sqrt(R^2 - x^2) の円を y = a で切った弓形。
  面積は s^2*acos(a/s) - a*sqrt(s^2 - a^2)。w = sqrt(c^2 - x^2)/a とおくと
  断面積 = a^2*((1+w^2)*atan(w) - w) = a^2*((2/3)w^3 - (2/15)w^5 + (2/35)w^7 - ...)。
  これを x で a から c まで積分する(w の最大値は約 0.202 と小さく、級数がすぐ収束する)。
  結果 V = 1.90201e-6 (別の見積もり (16/15)*z0^5/0.99 ≈ 1.905e-6, z0 = sqrt(0.005) とも一致)。
- p = 0.657 - 0.06075*pi + 12*V = 0.657 - 0.190851754 + 0.0000228241 = 0.4661711...

答え(a): 1 - pi/6
答え(b): 61/125 - 7*pi/250
答え(c): 0.4661711
