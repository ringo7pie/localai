## M1 の解答

K は凸体 T の平行体なので、シュタイナーの公式（Steiner formula）が全ての r >= 0 で成り立つ。

V(r) = Vol(T) + S * r + M * r^2 + (4*pi/3) * r^3

- Vol(T) = sqrt(2)/12
- S = 4 * (sqrt(3)/4) = sqrt(3)（表面積）
- 辺は 6 本、長さ 1、二面角 theta = acos(1/3)。各辺のまわりの扇形の中心角は pi - theta なので、
  M = 6 * (1 * (pi - theta) / 2) = 3 * (pi - acos(1/3))
- 頂点のまわりは合わせて半径 r の球 1 個分（体積 4*pi*r^3/3）

(a) r = 0.6 を入れる。

V = sqrt(2)/12 + 0.6*sqrt(3) + 3*0.36*(pi - acos(1/3)) + (4*pi/3)*0.216
  = sqrt(2)/12 + 0.6*sqrt(3) + 1.08*(pi - acos(1/3)) + 0.288*pi
  = sqrt(2)/12 + 0.6*sqrt(3) + 1.368*pi - 1.08*acos(1/3)
  約 4.12534

(b) 凸体の平行体の表面積は体積の r による微分に等しい。

S(r) = S + 2*M*r + 4*pi*r^2

r = 0.6 のとき、

S(0.6) = sqrt(3) + 6*(pi - acos(1/3))*0.6 + 4*pi*0.36
       = sqrt(3) + 3.6*(pi - acos(1/3)) + 1.44*pi
       = sqrt(3) + 5.04*pi - 3.6*acos(1/3)
       約 13.1342

（面の部分 sqrt(3)、辺の部分の円柱の側面 3.6*(pi - acos(1/3))、頂点の部分の球面 1.44*pi の合計である。）

答え(a): sqrt(2)/12 + 0.6*sqrt(3) + 1.368*pi - 1.08*acos(1/3)
答え(b): sqrt(3) + 5.04*pi - 3.6*acos(1/3)
