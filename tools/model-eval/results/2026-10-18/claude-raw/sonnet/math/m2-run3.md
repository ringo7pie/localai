## 解法

u = x - 1 とおく。V1 は線分 u∈[-1,0]（y=z=0）のまわりの距離 r 以内、V2 は線分 y∈[0,1]（u=z=0）のまわりの距離 r 以内の立体。
W = V1 \ V2 なので、体積・モーメントとも V1 の値から交わり I = V1∩V2 の値を引く。

### V1
- 体積 Vol1 = pi r^2 + (4/3) pi r^3
- 対称性から x の重心は 0.5、y の重心は 0。よって ∫x dV = 0.5 Vol1、∫y dV = 0。

### 交わり I
I は u∈[-r,r]、y∈[-r,r] の範囲にあり、(u,y) の符号で 4 つに分かれる。
- u<=0, y>=0: V1 の条件は y^2+z^2<=r^2、V2 の条件は u^2+z^2<=r^2 となる。2 本の円柱の交わり（Steinmetz 立体）の 1/4 で、体積は 4r^3/3。
  z ごとに s = sqrt(r^2-z^2) として箱 [-s,0]×[0,s] になる。
  ∫u dV = -(1/2)∫s^3 dz = -3 pi r^4/16、∫y dV = +3 pi r^4/16。
- それ以外の 3 つ（u>0,y>=0 / u<=0,y<0 / u>0,y<0）: 両方の条件が球 u^2+y^2+z^2<=r^2 になる。各 1/4 球で、体積は pi r^3/3、
  ∫u dV = ±pi r^4/8、∫y dV = ±pi r^4/8（符号は u と y の符号どおり）。

合計
- Vol_I = 4r^3/3 + pi r^3
- ∫u dV (I) = -3pi r^4/16 + pi r^4/8 - pi r^4/8 + pi r^4/8 = -pi r^4/16
- ∫y dV (I) = 3pi r^4/16 + pi r^4/8 - pi r^4/8 - pi r^4/8 = +pi r^4/16
- ∫x dV (I) = ∫u dV + Vol_I = Vol_I - pi r^4/16

### W
- 体積 V = Vol1 - Vol_I = pi r^2 + (pi-4) r^3/3
  r = 0.6 を入れると V = 0.432 pi - 0.288 ≈ 1.069168
- ∫x dV (W) = 0.5 Vol1 - (Vol_I - pi r^4/16) = pi r^2/2 - pi r^3/3 - 4r^3/3 + pi r^4/16
  r = 0.6 を入れると 0.1161 pi - 0.288 ≈ 0.0767389
- ∫y dV (W) = -pi r^4/16 = -0.0081 pi ≈ -0.0254469

### 重心
- x = (0.1161 pi - 0.288)/(0.432 pi - 0.288) ≈ 0.0717744
- y = -0.0081 pi/(0.432 pi - 0.288) ≈ -0.0238007

答え(a): 0.432*pi - 0.288
答え(b): (0.1161*pi - 0.288)/(0.432*pi - 0.288)
答え(c): -0.0081*pi/(0.432*pi - 0.288)
