## 解答 M3

### 方針

立方体の中心を原点にし、立方体を [-1/2, 1/2]^3 とする。点 x から最も近い面までの距離は 1/2 - max|x_i| である。
したがって「最も近い面までの距離が d 以下」は max|x_i| >= a と同じになる。ここで a = 1/2 - d とする。
「内接球の外側」は |x| > 1/2 である。

全体の立方体から球の内側を除いた部分の体積は 1 - pi/6 である。
ここから、小さい立方体 [-a, a]^3 のうち球の外側にある部分の体積を引くと p(d) になる。
小さい立方体の体積は (2a)^3 である。小さい立方体と球の共通部分の体積を W とすると、

p(d) = (1 - pi/6) - ((2a)^3 - W)

### (a) d = 1/4

a = 1/4 である。小さい立方体の頂点までの距離は sqrt(3)/4 ≈ 0.433 で、これは 1/2 より小さい。
小さい立方体は球の中に完全に入るので、W = (2a)^3 となる。
よって p = 1 - pi/6 ≈ 0.476401224。

### (b) d = 1/10

a = 2/5 である。球の半径 1/2 は a より大きいので、球は小さい立方体の面を突き出す。
突き出す部分は高さ h = 1/2 - 2/5 = 1/10 の球冠（cap）が 6 個である。
辺の中点までの距離は a*sqrt(2) ≈ 0.566 で 1/2 より大きいので、球冠どうしは重ならない。
球冠 1 個の体積は pi*h^2*(3R - h)/3 = pi*(1/100)*(7/5)/3 = 7*pi/1500 である（R = 1/2）。
W = pi/6 - 6*(7*pi/1500) = pi/6 - 7*pi/250 となる。
p = 1 - pi/6 - (4/5)^3 + pi/6 - 7*pi/250 = 61/125 - 7*pi/250 ≈ 0.400035406。

### (c) d = 3/20

a = 7/20 である。球冠の高さは h = 3/20 で、球冠 1 個の体積は pi*(9/400)*(27/20)/3 = 81*pi/8000 である。
今回は辺の中点までの距離 a*sqrt(2) ≈ 0.495 が 1/2 より小さいので、隣り合う面の球冠が辺の近くで重なる。
頂点までの距離は a*sqrt(3) ≈ 0.606 で 1/2 より大きいので、3 つの球冠が重なることはない。
したがって包除原理（inclusion-exclusion）で、

W = pi/6 - 6*V_cap + 12*V_pair

となる。V_pair は {x > a, y > a} を満たす球の部分の体積である（辺は 12 本）。

V_pair は、極座標で z 軸まわりの角度を使って積分する。
c^2 = R^2 - a^2 = 51/400 とおく。t = tan(phi) と置き換えると、

V_pair = (4/3) * J,  J = (積分 t=1..c/a) (c^2 - a^2*t^2)^(3/2) / (1 + t^2) dt

となる。これを計算すると

J = (1/8)*atan(sqrt(2)/10) - (1757/16000)*atan(sqrt(2)/7) + 49*sqrt(2)/16000 ≈ 1.4265e-6

を得る。
検算として、頂点近くで展開した近似値 V_pair ≈ 2*z0*eps^2/(15*a^2) * (1 - (2/7)*eps/a^2) を求めた。
ここで eps = 1/200、z0 = sqrt(eps) である。この近似値は 1.9017e-6 で、厳密式の 1.9020e-6 と 2e-4 の相対誤差で一致した。

p = 1 - (2a)^3 - 6*V_cap + 12*V_pair
  = 657/1000 - 243*pi/4000 + 16*J
  = 657/1000 - 243*pi/4000 + 2*atan(sqrt(2)/10) - (1757/1000)*atan(sqrt(2)/7) + 49*sqrt(2)/1000

数値は 0.466148246 + 0.0000228243 ≈ 0.466171071 である。

答え(a): 0.476401224
答え(b): 0.400035406
答え(c): 0.466171071
