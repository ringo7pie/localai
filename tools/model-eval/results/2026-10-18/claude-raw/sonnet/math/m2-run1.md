## 解法

V1 は線分 OA のまわりの半径 r のカプセル、V2 は線分 AB のまわりの半径 r のカプセル。V2 は A を中心とする球全体を含む。
u = x - 1 とおく。r = 0.6 < 1 なので、V1 の O 側の半球部分（x < 0）は V2 と交わらず、V2 の B 側の半球部分（y > 1）も V1 と交わらない。

共通部分 I = V1 ∩ V2 は次の 3 つに分かれる。

- A. y < 0 の半球（A 中心の球の y < 0 の側）。体積 (2/3) pi r^3、重心は x = 1, y = -3r/8。
- B. u > 0 かつ y >= 0 の 1/4 球。体積 (1/3) pi r^3、重心は x = 1 + 3r/8, y = 3r/8。
- C. u <= 0 かつ y >= 0 で、y^2 + z^2 <= r^2 と u^2 + z^2 <= r^2 を両方満たす部分（2 本の円柱の共通部分、Steinmetz 立体の 1/4）。体積 4 r^3 / 3。
  y 方向のモーメントは 3 pi r^4 / 16、u 方向のモーメントは -3 pi r^4 / 16。

したがって

- Vol(I) = pi r^3 + 4 r^3 / 3
- Mx(I) = Vol(I) - pi r^4 / 16
- My(I) = pi r^4 / 16

V1 は体積 pi r^2 + (4/3) pi r^3 = 0.648 pi、重心は (0.5, 0, 0)。よって Mx(V1) = 0.324 pi、My(V1) = 0。

r = 0.6（r^3 = 0.216, r^4 = 0.1296）を入れると

- Vol(W) = 0.648 pi - 0.216 pi - 0.288 = 0.432 pi - 0.288 = 1.069168...
- Mx(W) = 0.324 pi - (0.216 pi + 0.288 - 0.0081 pi) = 0.1161 pi - 0.288 = 0.0767389...
- My(W) = -0.0081 pi = -0.0254469...

重心の x 座標は 0.0767389 / 1.069168 = 0.0717744、y 座標は -0.0254469 / 1.069168 = -0.0238007。

答え(a): 0.432*pi - 0.288
答え(b): (0.1161*pi - 0.288)/(0.432*pi - 0.288)
答え(c): -0.0081*pi/(0.432*pi - 0.288)
