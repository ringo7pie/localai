考え方: u = x-1 とおく。O 側の半球は V2 と交わらず全部 W に入る。A 側の半球(x>1)は全部 V2 に含まれる。
0<=x<=1 の断面では、a=|u|<=r のとき、半径 r の円から「y<0 の半径 s=sqrt(r^2-a^2) の半円」と「y>=0, |z|<=s の帯」を除く。a>r のときは円全体が残る。

断面積 A(a) = pi r^2 - s a - r^2 asin(s/r) - pi s^2/2 (a<=r)
体積 = (2/3) pi r^3 + pi r^2 - r^3 (4+pi)/3 = pi r^2 + (pi-4) r^3/3
x のモーメント = pi r^2/2 - r^3 (4+pi)/3 + pi r^4/16
y のモーメント = -pi r^4/16 (断面ごとに -s a^2 を積分)

r = 0.6 を代入する。

答え(a): 0.36*pi + (pi-4)*0.216/3
答え(b): (0.18*pi - 0.216*(4+pi)/3 + pi*0.1296/16) / (0.36*pi + (pi-4)*0.216/3)
