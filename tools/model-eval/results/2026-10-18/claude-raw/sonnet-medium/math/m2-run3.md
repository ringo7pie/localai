高さ z の断面では、V1 は半径 rho = sqrt(r^2 - z^2) のスタジアム形（OA のまわり）、V2 は AB のまわりのスタジアム形になる。rho < 1 なので、交わりは A の近くだけで起きる。A を原点にした局所座標 (u, y) = (x - 1, y) で 4 つの象限に分けて数える。

- 交わりの断面積: rho^2 (1 + 3 pi / 4)
- 交わりの体積: V12 = (4/3) r^3 (1 + 3 pi / 4)
- 断面の積分: ∫u dA = -rho^3 / 6、∫y dA = +rho^3 / 6
- z 方向の積分: ∫ rho^3 dz = 3 pi r^4 / 8
- V1 の体積: pi r^2 + (4/3) pi r^3。重心は (1/2, 0, 0)。

W の体積は V1 - V12 = pi r^2 + pi r^3 / 3 - 4 r^3 / 3。

W の x 方向のモーメントは V1/2 - V12 + pi r^4 / 16、y 方向のモーメントは -pi r^4 / 16。

r = 0.6 を代入する。
