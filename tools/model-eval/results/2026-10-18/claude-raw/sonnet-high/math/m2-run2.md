## 方針

A を原点とする座標 u = x - 1 を使う。V1 は u 軸上の線分 [-1, 0] のまわり、V2 は y 軸方向の線分 [0, 1] のまわりの太さ r のカプセルである。r = 0.6 < 1 なので、V1 と V2 が重なるのは A の近傍 (|u| <= r, |y| <= r) だけである。

重なり I = V1 ∩ V2 を (u, y) の符号で 4 つの象限に分ける。

- u > 0, y >= 0: V1 の条件 u^2 + y^2 + z^2 <= r^2 が V2 の条件より強い。球の 1/4 になる。
- u <= 0, y < 0: V2 の条件が強い。球の 1/4 になる。
- u > 0, y < 0: 両方とも同じ球の条件で、球の 1/4 になる。
- u <= 0, y >= 0: 条件は z^2 <= r^2 - max(u^2, y^2) となる。体積 4r^3/3 の Steinmetz 型の部分である。

### 体積

|I| = pi r^3 + 4 r^3 / 3
|V1| = pi r^2 + 4 pi r^3 / 3
|W| = pi r^2 + pi r^3 / 3 - 4 r^3 / 3 = 0.432 pi - 0.288 ≈ 1.069168

### モーメント

V1 の u 方向のモーメントは -pi r^2 / 2 - 2 pi r^3 / 3 で、y 方向は 0 である。

I のモーメントは次のとおり。

- 球の 1/4 を 3 つ合わせると、u 方向が +pi r^4 / 8、y 方向が -pi r^4 / 8 になる。
- Steinmetz 型の部分は、u 方向が -3 pi r^4 / 16、y 方向が +3 pi r^4 / 16 になる。
- 合計は u 方向が -pi r^4 / 16、y 方向が +pi r^4 / 16 になる。

W のモーメントは、V1 のモーメントから I のモーメントを引いたものである。

- u 方向: -pi r^2 / 2 - 2 pi r^3 / 3 + pi r^4 / 16 = -0.3159 pi
- y 方向: -pi r^4 / 16 = -0.0081 pi

重心の x 座標は 1 + (u 方向のモーメント) / |W|、y 座標は (y 方向のモーメント) / |W| で求める。

- x ≈ 0.0717744
- y ≈ -0.0238007

答え(a): 0.432*pi - 0.288
答え(b): 1 - 0.3159*pi/(0.432*pi - 0.288)
答え(c): -0.0081*pi/(0.432*pi - 0.288)
