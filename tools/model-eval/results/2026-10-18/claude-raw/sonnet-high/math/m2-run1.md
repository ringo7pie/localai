## 考え方

r = 0.6。V1 は OA のまわりのカプセル、V2 は AB のまわりのカプセル。u = 1 - x とおく。

V1 の体積 = pi r^2 + (4/3) pi r^3 = 0.648 pi。

V1 と V2 の共通部分 I を、y の符号で分けて求める（V2 の y>1 の部分は V1 と交わらず、V1 の x<0 の部分は V2 と交わらない）。

- y>=0 かつ x<=1（u>=0）の部分: z ごとに、y と u が [0, s] の正方形（s = sqrt(r^2 - z^2)）になる。体積は 4/3 r^3、∫u dV = ∫y dV = 3 pi r^4 / 16。
- y>=0 かつ x>1 の部分: 球の 1/4。体積は pi r^3 / 3、∫|u| dV = ∫y dV = pi r^4 / 8。
- y<0 の部分: A を中心とする半球。体積は 2 pi r^3 / 3、∫y dV = -pi r^4 / 4、x の平均は 1。

合計:
- |I| = 4/3 r^3 + pi r^3 = 0.288 + 0.216 pi
- ∫x dV (I) = 4/3 r^3 + pi r^3 - pi r^4 / 16 = 0.288 + 0.2079 pi
- ∫y dV (I) = pi r^4 / 16 = 0.0081 pi

V1 のモーメント: ∫x dV = 0.5 pi r^2 + (2/3) pi r^3 = 0.324 pi、∫y dV = 0。

W = V1 \ V2 なので
- 体積 = 0.648 pi - 0.288 - 0.216 pi = 0.432 pi - 0.288 ≒ 1.069168
- ∫x dV (W) = 0.324 pi - 0.288 - 0.2079 pi = 0.1161 pi - 0.288 ≒ 0.0767389
- ∫y dV (W) = -0.0081 pi ≒ -0.0254469

重心: x ≒ 0.0717744、y ≒ -0.0238007

答え(a): 0.432*pi - 0.288
答え(b): (0.1161*pi - 0.288)/(0.432*pi - 0.288)
答え(c): -0.0081*pi/(0.432*pi - 0.288)
