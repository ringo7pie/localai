## M3 解答

立方体を [-1/2, 1/2]^3、球を半径 R = 1/2 とする。
求める確率 p(d) は、(球の外側の体積) - (内側の立方体 [-h, h]^3, h = 1/2 - d のうち球の外側にある体積) である。
面までの距離が d より大きい点の集合が内側の立方体 [-h, h]^3 になるため。

- 球の外側の体積: 1 - pi/6
- 内側の立方体のうち球の外側の体積: (2h)^3 - |球 ∩ 内側の立方体|
- |球 ∩ 内側の立方体| = 球の体積 - 6 * (球冠の体積) + 12 * (隣り合う 2 つの球冠の重なり)
  - 球冠の高さ a = R - h、体積 pi a^2 (3R - a) / 3
  - 2 つの球冠が重なるのは 2h^2 < R^2 のとき。3 つの重なりは 3h^2 < R^2 のときだけで、今回は起こらない。

### (a) d = 1/4, h = 1/4
内側の立方体の角までの距離は sqrt(3)/4 ≈ 0.433 < 1/2 なので、内側の立方体は球の中に収まる。
よって球の外側かつ内側の立方体の中の体積は 0。
p = 1 - pi/6 ≈ 0.476401

### (b) d = 1/10, h = 2/5
球冠の高さ a = 1/10。球冠の体積 = pi * 0.01 * 1.4 / 3。
2h^2 = 0.32 > 1/4 なので、球冠どうしは重ならない。
|球 ∩ 内側の立方体| = pi/6 - 6 * 0.014 pi / 3 = (1/6 - 0.028) pi。
球の外側の体積 = 0.512 - (1/6 - 0.028) pi。
p = 1 - pi/6 - 0.512 + (1/6 - 0.028) pi = 0.488 - 0.028 pi ≈ 0.4000354

### (c) d = 3/20, h = 7/20
a = 0.15。球冠の体積 = pi * 0.0225 * 1.35 / 3 = 0.010125 pi。6 個で 0.06075 pi。
2h^2 = 0.245 < 0.25 なので、隣り合う球冠が重なる（3 つ重なるのは 3h^2 = 0.3675 > 0.25 で起こらない）。
重なり V = {x > h, y > h} ∩ 球 の体積。極座標と置換 cot(theta) = w, w = (c/h) sin(phi)（c^2 = R^2 - h^2 = 51/400）で
V = (4/3)(c^4/h) * I, I = ∫ cos^4(phi) / (1 + k^2 sin^2(phi)) dphi（phi は asin(h/c) から pi/2 まで、k^2 = 51/49）。
t = tan(phi) と部分分数で
I = A*alpha + B*(alpha/2 - t1/(2(1+t1^2))) + C*(7/10)*atan(sqrt(2)/10)
（t1 = 7/sqrt(2)、alpha = atan(sqrt(2)/7)、A = -4900/2601、B = -49/51、C = 10000/2601）。
数値は I ≈ 3.07120e-5、c^4/h = 2601/56000 なので V ≈ 1.90195e-6、12V ≈ 2.28234e-5。
（z 方向の断面積から見積もった V ≈ 1.90e-6 とも合う。）

|球 ∩ 内側の立方体| = (1/6 - 0.06075) pi + 12V ≈ 0.3327470 + 0.0000228 = 0.3327698。
内側の立方体の体積 = 0.7^3 = 0.343。
球の外側かつ内側の立方体の中の体積 ≈ 0.0102302。
p = (1 - pi/6) - 0.0102302 ≈ 0.4764012 - 0.0102302 = 0.4661711

答え(a): 1 - pi/6
答え(b): 0.488 - 0.028*pi
答え(c): 0.466171
