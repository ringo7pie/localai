u = x - 1 とおく。V1 は u 軸上の線分 [-1,0] のまわり、V2 は y 軸方向の線分 y∈[0,1] のまわりの半径 r のカプセル。

V1 の体積は pi r^2 + (4/3) pi r^3。V1 は u = -1/2 について対称なので、V1 のモーメントは ∫u dV = -(1/2)·Vol(V1)、∫y dV = 0。

交わり V1∩V2 は次の 3 つに分かれる（u<-1 の端は V2 と交わらない）。
- P1: u≥0 の半球。体積 2 pi r^3/3。∫u = pi r^4/4、∫y = 0。
- P2: u≤0, y≤0 の 1/4 球。体積 pi r^3/3。∫u = -pi r^4/8、∫y = -pi r^4/8。
- P3: t=-u, 0≤t≤r, 0≤y≤r, |z|≤sqrt(r^2 - max(t,y)^2) の部分。体積 4 r^3/3。∫t = ∫y = 3 pi r^4/16。

交わりの体積は pi r^3 + 4 r^3/3。
交わりのモーメントは ∫u = -pi r^4/16、∫y = +pi r^4/16。

W の体積は pi r^2 + pi r^3/3 - 4 r^3/3。r = 0.6 を入れると 0.432 pi - 0.288 ≈ 1.069168。
∫_W u = -(1/2)(0.648 pi) + pi r^4/16 = -0.3159 pi。
∫_W x = ∫_W u + Vol(W) = 0.1161 pi - 0.288 ≈ 0.0767389。
∫_W y = -pi r^4/16 = -0.0081 pi ≈ -0.0254469。
z 方向は対称なので重心の z 座標は 0。
