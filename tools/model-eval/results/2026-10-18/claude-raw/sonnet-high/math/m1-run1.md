## M1 の解答

凸多面体の平行体には Steiner の公式が任意の r >= 0 で成り立つ。

V(r) = V_T + S r + (1/2) (sum_e L_e (pi - theta_e)) r^2 + (4 pi / 3) r^3

- 正四面体（1 辺 1）: V_T = sqrt(2)/12、表面積 S = sqrt(3)、二面角 theta = acos(1/3)、辺 6 本で長さ 1。
- 辺の項: (1/2) * 6 * (pi - acos(1/3)) * r^2 = 3 (pi - acos(1/3)) r^2
- 頂点の項: 法錐の立体角の和が 4 pi なので (4 pi / 3) r^3

(a) r = 0.6:
V = sqrt(2)/12 + 0.6 sqrt(3) + 1.08 (pi - acos(1/3)) + 0.288 pi
  = 0.117851 + 1.039230 + 2.063484 + 0.904779 = 4.125344

(b) 表面積は dV/dr（凸体の平行体では成り立つ）:
A(r) = S + 6 (pi - acos(1/3)) r + 4 pi r^2
     = sqrt(3) + 3.6 (pi - acos(1/3)) + 1.44 pi
     = 1.732051 + 6.878280 + 4.523893 = 13.134224

答え(a): sqrt(2)/12 + 0.6*sqrt(3) + 1.08*(pi - acos(1/3)) + 0.288*pi
答え(b): sqrt(3) + 3.6*(pi - acos(1/3)) + 1.44*pi
