## 方針

立方体を [-1/2, 1/2]^3 に置く。面までの最短距離は 1/2 - max|x_i| なので、
「最短距離が d 以下」は max|x_i| >= a (a = 1/2 - d) と同じ。
求める確率は 1 - Vol(球 ∪ 立方体 [-a, a]^3)。球の半径は R = 1/2。

Vol(球 ∪ 小立方体) = (2a)^3 + (面の外にはみ出す球冠 6 個の体積) - (球冠どうしの重なり)

球冠の高さは h = R - a = d で、体積は pi*d^2*(3R - d)/3。

### (a) d = 1/4, a = 1/4
a*sqrt(3) = 0.433 < 1/2 なので小立方体は球の内側に完全に入る。和集合は球そのもの。
p = 1 - pi/6 = 0.4764012244

### (b) d = 1/10, a = 2/5
a*sqrt(2) = 0.566 > 1/2 なので、辺付近は球の外で球冠どうしは重ならない。
p = 1 - (1-2d)^3 - 2*pi*d^2*(3/2 - d)
  = 1 - 0.512 - 0.028*pi
  = 0.488 - 0.028*pi = 0.4000354057

### (c) d = 3/20, a = 7/20
a*sqrt(2) = 0.495 < 1/2 なので、隣り合う 2 面の球冠が重なる(重なるのは 12 組)。
a*sqrt(3) の頂点側は球の外なので 3 つの重なりは無い。
6 個の球冠の体積: 6 * pi * 0.15^2 * (1.5 - 0.15)/3 = 0.06075*pi = 0.190851753
小立方体: 0.7^3 = 0.343
重なり V2 = {x>a, y>a, 球の内側} の体積。極座標で
V2 = (4/3) * ∫ (R^2 - a^2 csc^2 θ)^(3/2) dθ (θ は sinθ = 0.7 から pi/4 まで)
t = cotθ, t = (k/a) sinφ (k^2 = R^2 - a^2 = 0.1275) と置き、ψ = pi/2 - φ で級数展開すると
V2 = (4/3) * (k^4/a) * 0.49 * ∫_0^ψ1 sin^4ψ/(1 - 0.51 sin^2ψ) dψ  (sinψ1 = sqrt(0.005/0.1275))
  ≈ 1.9029e-6
12*V2 ≈ 2.2834e-5
和集合 = 0.343 + 0.190851753 - 0.000022834 = 0.533828919
p = 1 - 0.533828919 = 0.466171081

答え(a): 1 - pi/6
答え(b): 0.488 - 0.028*pi
答え(c): 0.466171
