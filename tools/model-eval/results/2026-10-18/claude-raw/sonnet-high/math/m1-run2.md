## 考え方

凸体の平行体に対するシュタイナーの公式を使う。K は凸体 T の r-近傍で、T は凸なので、次の式が全ての r >= 0 で成り立つ。

- 体積: V(r) = V0 + S r + (r^2/2) * sum_e l_e (pi - theta_e) + (4 pi / 3) r^3
- 表面積: A(r) = V'(r) = S + r * sum_e l_e (pi - theta_e) + 4 pi r^2

内訳は、面に垂直な角柱（面積 S × 厚さ r）、辺のまわりの円柱の扇形（外角 pi - theta、半径 r、長さ l）、頂点のまわりの球（4 頂点の外角の合計が全球になる）である。

1 辺 1 の正四面体では次のとおり。

- V0 = sqrt(2)/12
- S = 4 * (sqrt(3)/4) = sqrt(3)
- 二面角 theta = acos(1/3)、辺は 6 本で長さ 1。よって sum_e l_e (pi - theta_e) = 6 (pi - acos(1/3))

r = 0.6 を代入する。

(a) V = sqrt(2)/12 + 0.6 sqrt(3) + 0.36 * 3 (pi - acos(1/3)) + (4 pi / 3)(0.216)
  = sqrt(2)/12 + 0.6 sqrt(3) + 1.08 (pi - acos(1/3)) + 0.288 pi
  = 0.117851 + 1.039230 + 2.063483 + 0.904779
  = 4.125344

(b) A = sqrt(3) + 0.6 * 6 (pi - acos(1/3)) + 4 pi (0.36)
  = sqrt(3) + 3.6 (pi - acos(1/3)) + 1.44 pi
  = 1.732051 + 6.878280 + 4.523893
  = 13.134224

答え(a): sqrt(2)/12 + 0.6*sqrt(3) + 1.08*(pi - acos(1/3)) + 0.288*pi
答え(b): sqrt(3) + 3.6*(pi - acos(1/3)) + 1.44*pi
