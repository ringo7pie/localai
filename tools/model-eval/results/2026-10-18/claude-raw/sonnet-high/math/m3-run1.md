## 考え方

立方体を [-1/2, 1/2]^3 とし、R = 1/2、a = 1/2 - d とおく。
条件「面までの最小距離が d 以下」は max|x_i| >= a と同じ。つまり、立方体から内側の立方体 [-a, a]^3 を除いた「殻」の中にある。
殻の体積は 1 - (1 - 2d)^3 である。
求める確率は、殻のうち球の外側にある部分の体積になる。したがって、

p(d) = (殻の体積) - (殻と球の共通部分の体積)

である。共通部分は、6 つの面から飛び出す球冠(cap)の和集合になる。

- 球冠 1 つの体積は pi h^2 (3R - h) / 3。ここで h = R - a = d。
- 隣り合う 2 面の球冠は 2a^2 < R^2 のときだけ重なる。
- 3 面の球冠は 3a^2 < R^2 のときだけ重なる。
- 向かい合う面の球冠は重ならない。

### (a) d = 1/4

a = 1/4。内側の立方体の頂点までの距離の 2 乗は 3/16 < 1/4 なので、内側の立方体は球にすっぽり入る。
殻は球の外側の部分をすべて含むので、p = 立方体の体積 - 球の体積 = 1 - pi/6。

### (b) d = 1/10

a = 2/5。2a^2 = 0.32 > 0.25 なので、球冠どうしは重ならない。
殻の体積は 1 - 0.8^3 = 0.488。
球冠 1 つは pi · 0.01 · 1.4 / 3 なので、6 つで 0.028 pi。
p = 0.488 - 0.028 pi = 0.400035...

### (c) d = 3/20

a = 7/20。殻の体積は 1 - 0.7^3 = 0.657。
球冠 1 つは pi · 0.0225 · 1.35 / 3 = 0.010125 pi なので、6 つで 0.06075 pi。
2a^2 = 0.245 < 0.25 なので、隣り合う 2 面の球冠はわずかに重なる(12 組)。3 面の重なりは 3a^2 = 0.3675 > 0.25 で空。

2 面の重なり V は、極座標で次のように表せる。b^2 = R^2 - a^2 = 0.1275 として、

V = (4/3) ∫ (R^2 - a^2/sin^2 t)^(3/2) dt (t は asin(a/R) から pi/4 まで)

cot t = s と置き、s = (b/a) sin(u) と置き換えて有理化する。k = b^2/a^2 = 51/49 として積分すると、次のようになる。

V = (4/3)(b^4/a) · (1/k^2) · [ k I_s - (1 + 2k) Phi + (k + 1)^2 (7/10) atan(sqrt(2)/10) ]

- Phi = atan(sqrt(2)/7) = 0.199347208
- I_s = Phi/2 + 7 sqrt(2)/51/... の形(数値は 0.196727476)

数値は V = 1.90201e-6 になる。これは主要項の見積もり 1.92e-6 と約 1% の差で矛盾しない。

p = 0.657 - 0.06075 pi + 12 V = 0.657 - 0.190851753 + 0.0000228241 = 0.466171...

答え(a): 1 - pi/6
答え(b): 0.488 - 0.028*pi
答え(c): 0.4661711
