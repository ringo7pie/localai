## 考え方

T は凸体なので Steiner の公式が使える。K の体積は次の式になる。

V(r) = V0 + S r + M r^2 + (4 pi / 3) r^3

- V0 = sqrt(2)/12（正四面体の体積）
- S = sqrt(3)（表面積。正三角形 4 枚）
- 辺の寄与: 辺 6 本、長さ 1。二面角は acos(1/3) なので外角は phi = pi - acos(1/3)。各辺のまわりは中心角 phi の扇形柱で、体積は (phi/2) r^2。よって M = 6 * phi/2 = 3 phi。
- 頂点の寄与: 4 つの頂点を合わせて半径 r の球 1 個分、(4 pi / 3) r^3。

V(r) = sqrt(2)/12 + sqrt(3) r + 3 (pi - acos(1/3)) r^2 + (4 pi / 3) r^3

r = 0.6 を代入する。

V = sqrt(2)/12 + 0.6 sqrt(3) + 1.08 (pi - acos(1/3)) + 0.288 pi
  = 0.117851 + 1.039230 + 2.063484 + 0.904779
  = 4.125344

表面積は体積を r で微分したものである（外側への平行移動による）。

S(r) = dV/dr = sqrt(3) + 6 (pi - acos(1/3)) r + 4 pi r^2

r = 0.6 を代入する。

S = sqrt(3) + 3.6 (pi - acos(1/3)) + 1.44 pi
  = 1.732051 + 6.878280 + 4.523893
  = 13.134224

答え(a): sqrt(2)/12 + 0.6*sqrt(3) + 1.08*(pi - acos(1/3)) + 0.288*pi
答え(b): sqrt(3) + 3.6*(pi - acos(1/3)) + 1.44*pi
