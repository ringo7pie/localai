## 問題 M2 の解答

### 準備

A を原点に移した座標 u = x - 1 を使う。r = 0.6 = 3/5、r^3 = 27/125、r^4 = 81/625。

- V1 は線分 OA（u ∈ [-1, 0]）のまわりのカプセル（円柱 + 両端の半球）。体積は
  vol(V1) = π r^2 · 1 + (4/3) π r^3 = 45π/125 + 36π/125 = 81π/125。対称性から重心は (1/2, 0, 0)。
- V2 は線分 AB（y ∈ [0, 1]）のまわりのカプセル。

V2 の点は |u| ≤ r < 1 なので O 側の端の球は効かない。V1 の点は |y| ≤ r < 1 なので B 側の端の球も効かない。
したがって A の近くだけを考えればよく、

- C1 = {u ≤ 0, y^2 + z^2 ≤ r^2}、C2 = {y ≥ 0, u^2 + z^2 ≤ r^2}、B = A を中心とする半径 r の球

として、V1 ∩ V2 = (C1 ∪ B) ∩ (C2 ∪ B) = (C1 ∩ C2) ∪ B。

C1 ∩ C2 = Q は直交する 2 本の円柱の共通部分（Steinmetz の立体）のうち u ≤ 0, y ≥ 0 の 1/4。
球 B は両方の円柱に含まれるので、B ∩ Q は B の 1/4（u ≤ 0, y ≥ 0）である。

### (a) 体積

- vol(Q) = (1/4)(16 r^3 / 3) = 4 r^3 / 3
- vol(B) = 4π r^3 / 3、vol(B ∩ Q) = π r^3 / 3
- vol(V1 ∩ V2) = 4r^3/3 + 4πr^3/3 - πr^3/3 = r^3 (4/3 + π) = 36/125 + 27π/125

vol(W) = 81π/125 - 36/125 - 27π/125 = (54π - 36)/125 ≈ 1.06916803

### 1 次モーメント

高さ z での Q の断面は正方形 u ∈ [-s, 0], y ∈ [0, s]（s = sqrt(r^2 - z^2)）。
∫_{-r}^{r} (r^2 - z^2)^{3/2} dz = 3π r^4 / 8 を使うと

- ∫_Q y dV = (1/2)(3π r^4 / 8) = 3π r^4 / 16、∫_Q u dV = -3π r^4 / 16
- 1/4 球（u ≤ 0, y ≥ 0）: ∫ y dV = π r^4 / 8、∫ u dV = -π r^4 / 8
- 球 B の中心は A なので u, y のモーメントは 0

よって I = V1 ∩ V2 について
- M_y(I) = 3πr^4/16 - πr^4/8 = π r^4 / 16 = 81π/10000
- M_u(I) = -π r^4 / 16 なので M_x(I) = vol(I) - π r^4 / 16

### (b) 重心の x 座標

M_x(W) = (1/2)(81π/125) - (36/125 + 27π/125) + 81π/10000
       = (3240π - 2160π + 81π)/10000 - 2880/10000 = (1161π - 2880)/10000

vol(W) = (4320π - 2880)/10000 なので

x̄ = (1161π - 2880)/(4320π - 2880) = (129π - 320)/(480π - 320) ≈ 0.0717744126

### (c) 重心の y 座標

M_y(W) = 0 - 81π/10000 なので

ȳ = -81π/(4320π - 2880) = -9π/(480π - 320) ≈ -0.0238006561

答え(a): (54*pi - 36)/125
答え(b): (129*pi - 320)/(480*pi - 320)
答え(c): -9*pi/(480*pi - 320)
