## M2 の解答

r = 0.6 とする。r^3 = 0.216、r^4 = 0.1296。

### V1 の体積と 1 次モーメント

V1 は円柱（長さ 1、半径 r）と両端の半球 2 つでできたカプセル形である。

vol(V1) = pi r^2 + (4/3) pi r^3 = 0.36 pi + 0.288 pi = 0.648 pi

x = 1/2 と y = 0 に関して対称なので、∫x dV = 0.324 pi、∫y dV = 0。

### 交わり I = V1 ∩ V2

A を原点とする座標 u = x - 1、v = y をとる。V2 に入る点は |u| <= r、V1 に入る点は |v| <= r を満たす。
r = 0.6 < 1 なので、O 側・B 側の端は交わりに関係しない。
したがって、OA は A から -u 方向へ伸びる半直線、AB は A から +v 方向へ伸びる半直線とみなしてよい。

- u <= 0, v >= 0: v^2 + z^2 <= r^2 かつ u^2 + z^2 <= r^2。高さ z での断面は一辺 s = sqrt(r^2 - z^2) の正方形になる。
  体積は ∫(r^2 - z^2) dz = 4r^3/3。
  ∫u dV = -(1/2)∫s^3 dz = -(1/2)(3 pi/8) r^4 = -(3 pi/16) r^4、∫v dV = +(3 pi/16) r^4。
- u > 0, v >= 0: 半径 r の球の 1/4 になる。体積は pi r^3/3、∫u = pi r^4/8、∫v = pi r^4/8。
- u <= 0, v < 0: 球の 1/4 になる。体積は pi r^3/3、∫u = -pi r^4/8、∫v = -pi r^4/8。
- u > 0, v < 0: 球の 1/4 になる。体積は pi r^3/3、∫u = pi r^4/8、∫v = -pi r^4/8。

まとめると:

vol(I) = 4r^3/3 + pi r^3 = 0.288 + 0.216 pi
∫u dV = -(pi/16) r^4 = -0.0081 pi
∫v dV = +(pi/16) r^4 = +0.0081 pi

（(u, v) → (-v, -u) の対称性から ∫u = -∫v となり、上の結果と合う。）

よって ∫x dV = vol(I) + ∫u = 0.288 + 0.216 pi - 0.0081 pi、∫y dV = 0.0081 pi。

### W = V1 \ V2

(a) vol(W) = 0.648 pi - 0.288 - 0.216 pi = 0.432 pi - 0.288 = 18(3 pi - 2)/125 ≈ 1.06916803

(b) ∫x dV over W = 0.324 pi - (0.288 + 0.216 pi - 0.0081 pi) = 0.1161 pi - 0.288
  x̄ = (0.1161 pi - 0.288)/(0.432 pi - 0.288) = (129 pi - 320)/(160(3 pi - 2)) ≈ 0.0717744126

(c) ∫y dV over W = 0 - 0.0081 pi = -0.0081 pi
  ȳ = -0.0081 pi/(0.432 pi - 0.288) = -9 pi/(160(3 pi - 2)) ≈ -0.0238006561

答え(a): 18*(3*pi-2)/125
答え(b): (129*pi-320)/(160*(3*pi-2))
答え(c): -9*pi/(160*(3*pi-2))
