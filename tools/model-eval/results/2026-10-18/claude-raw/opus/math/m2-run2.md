## 問題 M2 の解答

### 考え方

V1 は線分 OA のまわりのカプセル（円柱＋両端の半球）で、体積は
pi r^2 * 1 + (4/3) pi r^3 = 0.36 pi + 0.288 pi = 0.648 pi。重心は (0.5, 0, 0)（対称性）。

W = V1 \ V2 なので、vol(W) = vol(V1) - vol(V1 ∩ V2)、モーメントも同様に引けばよい。

**V1 ∩ V2 の形**

A を原点に移した座標 u = x - 1 をとる。V2 に入るには |u| <= r、V1 に入るには |y| <= r が必要なので、
共通部分は A の近く（u ∈ [-0.6, 0.6]、y ∈ [-0.6, 0.6]）だけにあり、線分の反対側の端（O や B）は効かない。
したがって「A から -u 方向へ伸びる半無限カプセル」と「A から +y 方向へ伸びる半無限カプセル」の共通部分と同じ。

(u, y) の符号で 4 つに分ける。

- u <= 0, y >= 0: y^2 + z^2 <= r^2 かつ u^2 + z^2 <= r^2。直交 2 円柱（Steinmetz 立体、体積 16r^3/3）の 1/4 で、体積 4r^3/3。
- u > 0, y >= 0: 球 u^2 + y^2 + z^2 <= r^2 の 1/4（もう一方の条件は自動的に満たす）。体積 pi r^3/3。
- u <= 0, y < 0: 同じく球の 1/4。体積 pi r^3/3。
- u > 0, y < 0: 球の 1/4。体積 pi r^3/3。

vol(V1 ∩ V2) = pi r^3 + 4r^3/3 = 0.216 pi + 0.288。

**(a) 体積**

vol(W) = 0.648 pi - 0.216 pi - 0.288 = 0.432 pi - 0.288 = 0.144 (3 pi - 2) ≈ 1.06916802635

**モーメント（A 基準の u, y）**

- 1/4 球: 重心は各座標とも ±3r/8。各片のモーメントの大きさは (pi r^3/3)(3r/8) = pi r^4/8。
  3 片の和: M_u = +pi r^4/8、M_y = -pi r^4/8。
- 1/4 Steinmetz: 高さ z の断面は一辺 s = sqrt(r^2 - z^2) の正方形の 1/4（u ∈ [-s, 0]、y ∈ [0, s]）。
  ∫u dA = -s^3/2。∫_{-r}^{r} (r^2 - z^2)^{3/2} dz = 3 pi r^4/8 なので、M_u = -3 pi r^4/16、M_y = +3 pi r^4/16。

合計: M_u(∩) = -pi r^4/16、M_y(∩) = +pi r^4/16。r^4 = 0.1296 なので pi r^4/16 = 0.0081 pi。

**(b) 重心の x 座標**

M_x(∩) = vol(∩) + M_u(∩) = 0.216 pi + 0.288 - 0.0081 pi
M_x(W) = 0.324 pi - (0.216 pi + 0.288 - 0.0081 pi) = 0.1161 pi - 0.288

x̄ = (0.1161 pi - 0.288) / (0.432 pi - 0.288) = (129 pi - 320) / (160 (3 pi - 2)) ≈ 0.0717744127

**(c) 重心の y 座標**

M_y(W) = 0 - 0.0081 pi

ȳ = -0.0081 pi / (0.432 pi - 0.288) = -9 pi / (160 (3 pi - 2)) ≈ -0.0238006561

（検算: W を「左の半球」「x ∈ [0, 0.4] の円柱」「x ∈ [0.4, 1] の円柱から 1/4 Steinmetz と 1/4 球を除いた部分」に分けて数値で足しても、体積 約 1.0692、x̄ 約 0.07177 で一致する。）

答え(a): 0.432*pi - 0.288
答え(b): (129*pi - 320)/(160*(3*pi - 2))
答え(c): -9*pi/(160*(3*pi - 2))
