## 問題 M3 の解答

### 考え方

立方体の中心を原点にとり、立方体を [-1/2, 1/2]^3 とする。立方体の体積は 1 なので、確率は体積と同じになる。

- 面までの最小距離は 1/2 - max(|x|,|y|,|z|)。これが d 以下になる条件は max(|x|,|y|,|z|) >= a（a = 1/2 - d）。つまり P は内側の立方体 Q_a = [-a, a]^3 の外にある。
- 内接球 B の半径は R = 1/2。

よって次の式が成り立つ。

p(d) = Vol(B の外) - Vol(Q_a ∩ B の外) = (1 - pi/6) - [(2a)^3 - Vol(Q_a ∩ B)]

B から Q_a の外を除く部分は、包除原理（inclusion-exclusion）で次のように数える。

- C: 1 つの面の外側にある球冠（高さ h = R - a）の体積。C = pi h^2 (R - h/3)
- E: 隣り合う 2 つの面の外側の共通部分 {x>a, y>a, r<R} の体積。2a^2 < R^2 のときだけ正になる
- T: 3 つの面の外側の共通部分。3a^2 < R^2 のときだけ正になる

Vol(Q_a ∩ B) = pi/6 - 6C + 12E - 8T なので、次の式になる。

p(d) = 1 - (2a)^3 - 6C + 12E - 8T

ただし Q_a が B に丸ごと含まれる（sqrt(3) a <= R）ときは、Q_a ∩ B の外 が空になり、p = 1 - pi/6 となる。

**E の閉じた式**（z で積分し、部分積分と置換 z = c sinθ を使って求めた）:

E = (2/3) a^2 z0 - (2/3) a (3R^2 - a^2) atan(z0/a) + (4/3) R^3 atan(z0/R)、ここで z0 = sqrt(R^2 - 2a^2)

検算: a = 0 では pi R^3 / 3（球の 1/4）になり、z0 = 0 では 0 になる。a = 0 での微分も -pi R^2 で合う。

### (a) d = 1/4

a = 1/4 で、sqrt(3)/4 ≈ 0.433 < 1/2。Q_a は球の内側に丸ごと入る。

p = 1 - pi/6 ≈ 0.476401224

### (b) d = 1/10

a = 2/5 で、2a^2 = 0.32 > 1/4。球冠どうしは重ならないので E = T = 0。h = 1/10 なので C = pi (1/100)(1/2 - 1/30) = 7pi/1500。

p = 1 - 0.512 - 6·7pi/1500 = 61/125 - 7pi/250 ≈ 0.400035406

### (c) d = 3/20

a = 7/20 で、2a^2 = 0.245 < 0.25 < 3a^2 なので、E > 0、T = 0。

- (2a)^3 = 0.343
- h = 0.15 なので C = pi·0.0225·0.45 = 81pi/8000、6C = 243pi/4000
- z0 = sqrt(1/4 - 98/400) = sqrt(2)/20、z0/a = sqrt(2)/7、z0/R = sqrt(2)/10
- E = [49 sqrt(2) - 1757 atan(sqrt(2)/7) + 2000 atan(sqrt(2)/10)] / 12000 ≈ 1.90201e-6

p = 657/1000 - 243pi/4000 + [49 sqrt(2) - 1757 atan(sqrt(2)/7) + 2000 atan(sqrt(2)/10)]/1000 ≈ 0.466171070

答え(a): 1 - pi/6
答え(b): 61/125 - 7*pi/250
答え(c): 657/1000 - 243*pi/4000 + (49*sqrt(2) - 1757*atan(sqrt(2)/7) + 2000*atan(sqrt(2)/10))/1000
