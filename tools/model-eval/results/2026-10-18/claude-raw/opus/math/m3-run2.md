## 考え方

立方体を中心が原点の [-1/2, 1/2]^3 とし、内接球の半径を r = 1/2 とする。
「面までの最小距離が d より大きい」点の集まりは、内側の立方体 [-h, h]^3（h = 1/2 - d、体積 (1-2d)^3）である。

p(d) = P(球の外) - P(球の外 かつ 内側の立方体の中)
     = (1 - pi/6) - [ (1-2d)^3 - V(球 ∩ 内側の立方体) ]

V(球 ∩ 内側の立方体) は h と r の関係で決まる。

- r <= h*sqrt(3)… ではなく、h*sqrt(3) <= r のとき（内側の立方体がすべて球の中）: V = (2h)^3
- h <= r <= h*sqrt(2) のとき: 球から 6 つの球冠（高さ t = r - h、体積 pi t^2 (3r - t)/3）を引く。球冠どうしは重ならない。
- h*sqrt(2) <= r <= h*sqrt(3) のとき: 隣り合う球冠が重なる（12 本の辺の付近）。3 つの重なりは無い。
  V = pi/6 - 6*(球冠) + 12*W、W = {x>h, y>h, x^2+y^2+z^2<r^2} の体積。

W は極座標で計算する（対称性で θ ≤ pi/4 の半分を 2 倍、u = cot θ と置換）:
W = (4/3) h^3 ∫_1^k (k^2-u^2)^(3/2)/(1+u^2) du、k^2 = (r^2-h^2)/h^2、a = sqrt(k^2+1) = r/h
∫ の値 = a^3 atan(sqrt(k^2-1)/a) - (a^2 + k^2/2) acos(1/k) + sqrt(k^2-1)/2

### (a) d = 1/4
h = 1/4、h*sqrt(3) = 0.433 < 1/2。内側の立方体は球にすっぽり入るので、球の外の点は必ず最小距離 ≤ 1/4。
p(1/4) = 1 - pi/6 ≈ 0.476401224

### (b) d = 1/10
h = 2/5、h < r = 1/2 < h*sqrt(2) = 0.566。球冠の高さ t = 1/10、6 個で 6 * pi*(1/100)*(3/2 - 1/10)/3 = 7pi/250。
V = pi/6 - 7pi/250、内側の立方体 = 0.512。
p = 1 - pi/6 - 0.512 + pi/6 - 7pi/250 = 61/125 - 7pi/250 ≈ 0.400035406

### (c) d = 3/20
h = 7/20、h*sqrt(2) = 0.495 < r = 1/2 < h*sqrt(3)。
球冠の高さ t = 3/20、6 個で 243pi/4000。内側の立方体 = 0.343。
k^2 = 51/49、a = 10/7、sqrt(k^2-1) = sqrt(2)/7、acos(7/sqrt(51)) = atan(sqrt(2)/7)。
12W = 2 atan(sqrt(2)/10) - (1757/1000) atan(sqrt(2)/7) + 49 sqrt(2)/1000 ≈ 2.28241e-5
（近似計算 W ≈ ∫ L^2/2 dz の補正込みで 1.9017e-6 となり、W ≈ 1.90201e-6 と一致することを確認）

p = 1 - pi/6 - 0.343 + pi/6 - 243pi/4000 + 12W
  = 657/1000 - 243pi/4000 + 2 atan(sqrt(2)/10) - (1757/1000) atan(sqrt(2)/7) + 49 sqrt(2)/1000
  ≈ 0.466171070

答え(a): 1 - pi/6
答え(b): 61/125 - 7*pi/250
答え(c): 657/1000 - 243*pi/4000 + 2*atan(sqrt(2)/10) - 1757*atan(sqrt(2)/7)/1000 + 49*sqrt(2)/1000
