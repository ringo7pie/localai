## 問題 M1 の解答

K は凸多面体 T の平行体（parallel body）なので、シュタイナーの公式（Steiner formula）で求められる。K は次の部分に分かれる。

- T 本体
- 各面の上に厚さ r で立つ板（面積 × r）
- 各辺のまわりの円柱の扇形部分（中心角 = π − 二面角）
- 各頂点のまわりの球の一部（4 頂点の合計がちょうど球 1 個分になる）

正四面体（1 辺 1）のデータ:
- 体積 V = sqrt(2)/12
- 表面積 S = sqrt(3)
- 辺は 6 本、長さはどれも 1
- 二面角 θ = acos(1/3)、なので π − θ = acos(-1/3)

### (a) 体積

V(K) = V + S·r + Σ_辺 L·(π − θ)/2 · r² + (4/3)π r³
= sqrt(2)/12 + sqrt(3)·r + 3·acos(-1/3)·r² + (4/3)π r³

r = 0.6 を代入すると:
= sqrt(2)/12 + (3/5)sqrt(3) + (27/25)acos(-1/3) + (36/125)pi
≈ 0.117851130 + 1.039230485 + 2.063483895 + 0.904778684
≈ 4.12534419

### (b) 表面積

S(K) = S + Σ_辺 L·(π − θ)·r + 4π r²
= sqrt(3) + 6·acos(-1/3)·r + 4π r²

r = 0.6 を代入すると:
= sqrt(3) + (18/5)acos(-1/3) + (36/25)pi
≈ 1.732050808 + 6.878279650 + 4.523893421
≈ 13.1342239

答え(a): sqrt(2)/12 + 3*sqrt(3)/5 + (27/25)*acos(-1/3) + (36/125)*pi
答え(b): sqrt(3) + (18/5)*acos(-1/3) + (36/25)*pi
