## M3 の解答

立方体を中心が原点になるよう [-1/2, 1/2]^3 に置く。面までの最小距離は 1/2 - max(|x|,|y|,|z|) なので、
「最小距離が d 以下」は「P が内側の立方体 C_a = [-a, a]^3（a = 1/2 - d）の外にある」と同じ。
球 B の半径を R = 1/2 とすると

p(d) = 1 - Vol(C_a ∪ B) = 1 - (2a)^3 - Vol(B \ C_a)

B \ C_a は、球のうち |x|>a などの部分（6 つの球冠）の和集合。包除原理で
Vol(B \ C_a) = 6·Cap - 12·E + (3 つの重なり)。
- Cap = π h^2 (3R - h)/3、h = R - a
- E = Vol{x>a, y>a, x^2+y^2+z^2<R^2}（辺の近くの重なり。a√2 < R のときだけ 0 でない）
- 3 つの重なりは a√3 < R のときだけ 0 でない

### (a) d = 1/4
a = 1/4。立方体 C_a の頂点までの距離は a√3 ≈ 0.433 < 1/2 なので、C_a は球の中に入る。
C_a ∪ B = B だから p = 1 - π/6。

### (b) d = 1/10
a = 0.4。a√2 ≈ 0.566 > 1/2 なので球冠どうしは重ならない。h = 0.1。
Cap = π(0.01)(1.4)/3、6 個で 0.028π。
p = 1 - 0.512 - 0.028π = 61/125 - 7π/250 ≈ 0.400035405699

### (c) d = 3/20
a = 0.35。a√2 ≈ 0.495 < 1/2 < a√3 なので、辺の重なり（12 本）はあるが、頂点の重なりは無い。
h = 0.15、Cap = π(0.0225)(1.35)/3 = 0.010125π、6 個で 0.06075π。

単位球（半径 1）で V(b) = Vol{x>b, y>b, |r|<1} を積分すると（s = sqrt(1-2b^2)）
V(b) = (2/3)·atan(s/b^2) - 2b(1 - b^2/3)·atan(s/b) + (2/3)·b^2·s
（b=0 で π/3、b=1/√2 で 0、b→1/√2 の展開の主項 4s^5/15 も直接の近似と一致）。
半径 1/2 では E = V(0.7)/8。b = 0.7 で s = √2/10、s/b = √2/7、s/b^2 = 10√2/49。

12E = 1.5·V(0.7) = atan(10√2/49) - (1757/1000)·atan(√2/7) + 49√2/1000 ≈ 0.0000228241334

p = 1 - 0.343 - 0.06075π + 12E
  = 657/1000 - 243π/4000 + atan(10√2/49) - (1757/1000)·atan(√2/7) + 49√2/1000
  ≈ 0.466171070428

答え(a): 0.476401224402
答え(b): 0.400035405699
答え(c): 0.466171070428
