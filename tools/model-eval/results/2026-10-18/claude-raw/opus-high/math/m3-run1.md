## 問題 M3 の解答

立方体の中心を原点にとり、立方体を [-1/2, 1/2]^3 とする。球の半径は r = 1/2。
面までの最小距離が d より大きい点の集合は、内側の立方体 [-a, a]^3（a = 1/2 - d）である。よって

p(d) = (球の外側の体積) - (内側の立方体のうち球の外側の体積)
     = (1 - pi/6) - [ (2a)^3 - Vol(球 ∩ 内側の立方体) ]

### Vol(球 ∩ [-a,a]^3) の求め方

- 球が面からはみ出す 1 か所のキャップの体積: 高さ h = r - a として V_cap = pi h^2 (3r - h)/3
- a√2 < r（球が辺を越える）のとき、隣り合う 2 つのキャップが重なる。辺 1 本あたりの重なり
  V_edge = Vol{x > a, y > a, x^2+y^2+z^2 < r^2}
  を z について積分して部分積分すると（z0 = sqrt(r^2 - 2a^2)）
  V_edge = (4r^3/3) atan(z0/r) - (2a/3)(3r^2 - a^2) atan(z0/a) + (2/3) a^2 z0
  （a = 0 のとき pi r^3/3 = 球の 1/4 になり、a = r/√2 のとき 0 になることで確認）
- a√3 > r なら 3 つのキャップの重なりは無い。
- Vol(球 ∩ 立方体) = pi/6 - 6 V_cap + 12 V_edge

### (a) d = 1/4

a = 1/4。内側の立方体の頂点までの距離は √3/4 ≈ 0.433 < 1/2 なので、内側の立方体は球の中に入る。
p = 1 - pi/6 ≈ 0.476401

### (b) d = 1/10

a = 2/5。a√2 ≈ 0.566 > 1/2 なので、キャップどうしは重ならない。h = 1/10。
V_cap = pi (1/100)(3/2 - 1/10)/3 = 7pi/1500。
p = (1 - pi/6) - 0.512 + (pi/6 - 6·7pi/1500) = 0.488 - 7pi/250 ≈ 0.400035

### (c) d = 3/20

a = 7/20。a√2 ≈ 0.49497 < 1/2 < a√3 なので、辺での重なりがあり、頂点での重なりは無い。
h = 3/20、6 V_cap = 6·pi(0.0225)(1.35)/3 = 243pi/4000。
z0 = sqrt(1/4 - 2·49/400) = √2/20。
V_edge = (1/6) atan(√2/10) - (1757/12000) atan(√2/7) + 49√2/12000 ≈ 1.90201e-6
p = 0.657 - 243pi/4000 + 12 V_edge
  = 657/1000 - 243pi/4000 + 2 atan(√2/10) - (1757/1000) atan(√2/7) + 49√2/1000
  ≈ 0.466171

答え(a): 1 - pi/6
答え(b): 488/1000 - 7*pi/250
答え(c): 657/1000 - 243*pi/4000 + 2*atan(sqrt(2)/10) - 1757/1000*atan(sqrt(2)/7) + 49*sqrt(2)/1000
