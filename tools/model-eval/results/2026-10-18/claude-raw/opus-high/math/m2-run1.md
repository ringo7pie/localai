## 考え方

V1 は線分 OA のまわりのカプセル、V2 は線分 AB のまわりのカプセル（半径 r = 0.6）。
Vol(W) = Vol(V1) - Vol(I)、I = V1 ∩ V2。

- Vol(V1) = π r^2 · 1 + (4/3) π r^3 = 0.648π。重心は (0.5, 0, 0)。

I は x ≥ 0.4 にあるので、u = x - 1 とおいて A を原点に移す。V1 は u ≤ 0 側に伸び、V2 は y ≥ 0 側に伸びる。
- u ≤ 0, y ≥ 0: y^2+z^2 ≤ r^2 かつ u^2+z^2 ≤ r^2（直交する 2 本の円柱の共通部分の 1/4）。体積 4r^3/3。
- それ以外の 3 つの象限: 球 u^2+y^2+z^2 ≤ r^2 の 1/4 ずつ。合計 π r^3。

Vol(I) = 4r^3/3 + π r^3 = 0.288 + 0.216π。
Vol(W) = 0.648π - 0.216π - 0.288 = 0.432π - 0.288 = 18(3π - 2)/125。

モーメント（u, y について）:
- 球の 1/4 の各部分: ±π r^4/8。3 つの和は M_u = +π r^4/8、M_y = -π r^4/8。
- 円柱の共通部分の 1/4: 断面は一辺 s = sqrt(r^2 - z^2) の正方形。∫(r^2 - z^2)^{3/2} dz = 3π r^4/8 より、M_u = -3π r^4/16、M_y = +3π r^4/16。
- I の合計: M_u = -π r^4/16、M_y = +π r^4/16（π r^4/16 = 0.0081π）。
- I の x モーメント = Vol(I) - 0.0081π = 0.288 + 0.2079π。

W のモーメント:
- M_x = 0.324π - 0.288 - 0.2079π = 0.1161π - 0.288
- M_y = -0.0081π

重心:
- x = (0.1161π - 0.288)/(0.432π - 0.288) = (129π - 320)/(160(3π - 2)) ≈ 0.0717744
- y = -0.0081π/(0.432π - 0.288) = -9π/(160(3π - 2)) ≈ -0.0238007

答え(a): 18*(3*pi - 2)/125
答え(b): (129*pi - 320)/(160*(3*pi - 2))
答え(c): -9*pi/(160*(3*pi - 2))
