## 問題 M1 の解答

K は凸体 T と半径 r の球のミンコフスキー和（平行体）なので、シュタイナーの公式が使える。

- T の体積: V = sqrt(2)/12
- T の表面積: S = 4 * (sqrt(3)/4) = sqrt(3)
- 二面角: θ = acos(1/3)
- 辺の寄与: 各辺（長さ 1、6 本）のまわりは中心角 (π - θ) の円柱の一部

体積:
V(K) = V + S r + [Σ_辺 L (π - θ)/2] r^2 + (4/3)π r^3
     = sqrt(2)/12 + sqrt(3) r + 3(π - acos(1/3)) r^2 + (4/3)π r^3

表面積:
S(K) = S + 2 [Σ_辺 L (π - θ)/2] r + 4π r^2
     = sqrt(3) + 6(π - acos(1/3)) r + 4π r^2

r = 0.6 を代入する。

(a) V(K) = sqrt(2)/12 + 3*sqrt(3)/5 + 1.08(π - acos(1/3)) + 0.288π
        = sqrt(2)/12 + 3*sqrt(3)/5 + 1.368π - 1.08 acos(1/3)
        ≈ 0.117851130 + 1.039230485 + 2.063483896 + 0.904778684
        ≈ 4.12534420

(b) S(K) = sqrt(3) + 3.6(π - acos(1/3)) + 1.44π
        = sqrt(3) + 5.04π - 3.6 acos(1/3)
        ≈ 1.732050808 + 6.878279652 + 4.523893421
        ≈ 13.1342239

答え(a): sqrt(2)/12 + 3*sqrt(3)/5 + 1.368*pi - 1.08*acos(1/3)
答え(b): sqrt(3) + 5.04*pi - 3.6*acos(1/3)
