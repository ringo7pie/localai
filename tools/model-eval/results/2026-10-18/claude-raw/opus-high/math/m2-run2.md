## 考え方

A を原点にとり u = x − 1 とする。V1 の O 側の半球（u ≤ −1）は V2（|u| ≤ r）と交わらず、V2 の B 側の半球（y ≥ 1）は V1（|y| ≤ r）と交わらない。よって A の近くでは

- V1 = { y² + z² + max(u,0)² ≤ r² }
- V2 = { u² + z² + min(y,0)² ≤ r² }

V1 の体積 = πr²·1 + (4/3)πr³ = 0.648π、x 重心 0.5、y 重心 0。

交わり I = V1 ∩ V2 を (u, y) の符号で 4 つに分ける。

- u ≤ 0, y ≥ 0: 直交する 2 本の円柱の交わり（Steinmetz 立体）の 1/4 → 体積 4r³/3、∫u dV = −3πr⁴/16、∫y dV = +3πr⁴/16
- 残り 3 象限: どれも球の 1/4 → 各体積 πr³/3、∫u, ∫y はそれぞれ ±πr⁴/8

合計: Vol(I) = 4r³/3 + πr³、∫u dV = −πr⁴/16、∫y dV = +πr⁴/16。

r = 0.6 のとき:

- Vol(W) = 0.648π − 0.288 − 0.216π = 0.432π − 0.288 = (54π − 36)/125 ≈ 1.06916803
- x のモーメント: 0.324π − (0.288 + 0.216π − 0.0081π) = 0.1161π − 0.288
  → x̄ = (129π − 320)/(480π − 320) ≈ 0.0717744
- y のモーメント: 0 − 0.0081π
  → ȳ = −9π/(480π − 320) ≈ −0.0238007

答え(a): (54*pi - 36)/125
答え(b): (129*pi - 320)/(480*pi - 320)
答え(c): -9*pi/(480*pi - 320)
