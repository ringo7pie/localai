## 考え方

立方体の中心を原点にとり、立方体を [-1/2, 1/2]^3、内接球を半径 R = 1/2 の球 B とする。
「面までの最小距離が d 以下」は、P が内側の立方体 Q = [-a, a]^3（a = 1/2 - d）の外にあることと同じ。

p(d) = (立方体のうち B の外の体積) - (Q のうち B の外の体積)
     = (1 - pi/6) - (8a^3 - V(a))、 V(a) = vol(B ∩ Q)

### (a) d = 1/4, a = 1/4
a*sqrt(3) = 0.433 < 1/2 なので Q は B に完全に含まれる。V = 8a^3。
p = 1 - pi/6

### (b) d = 1/10, a = 2/5
a < R かつ a*sqrt(2) > R なので、B は Q の 6 面から球冠がはみ出すだけ（辺には届かない）。
球冠の高さ h = 1/10、体積 C = pi h^2 (3R - h)/3 = 7pi/1500、6C = 7pi/250。
V = pi/6 - 7pi/250、8a^3 = 0.512。
p = 1 - 0.512 - 7pi/250 = 61/125 - 7pi/250 ≈ 0.400035

### (c) d = 3/20, a = 7/20
a*sqrt(2) < R < a*sqrt(3) なので、球冠どうしが辺の近くで重なる（頂点には届かない）。
包除原理で V = pi/6 - 6C + 12W。
C: h = 3/20、C = pi(0.0225)(1.35)/3 = 0.010125 pi、6C = 243pi/4000。
W = vol{x > a, y > a} ∩ B は積分して
W = -2aR^2 φ + (2/3)a^3 φ + (2/3)a^2 k + (2R^3/3)(pi/2 - atan(a^2/(R k)))、
k = sqrt(R^2 - 2a^2) = sqrt(2)/20、φ = acos(a/sqrt(R^2 - a^2)) = atan(sqrt(2)/7)。
代入すると
12W = -(1757/1000) atan(sqrt(2)/7) + 49 sqrt(2)/1000 + atan(10 sqrt(2)/49) ≈ 2.28241e-5
8a^3 = 0.343 なので
p = 1 - 0.343 - 243pi/4000 + 12W
  = 657/1000 - 243*pi/4000 + 49*sqrt(2)/1000 - (1757/1000)*atan(sqrt(2)/7) + atan(10*sqrt(2)/49)
  ≈ 0.466171070

答え(a): 1 - pi/6
答え(b): 61/125 - 7*pi/250
答え(c): 657/1000 - 243*pi/4000 + 49*sqrt(2)/1000 - (1757/1000)*atan(sqrt(2)/7) + atan(10*sqrt(2)/49)
