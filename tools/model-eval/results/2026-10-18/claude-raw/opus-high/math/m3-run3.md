## 考え方

立方体の中心を原点にとり、P = (x, y, z) ∈ [-1/2, 1/2]^3 とする。r = 1/2 を内接球の半径とする。
面までの最小距離 = 1/2 - max(|x|,|y|,|z|) なので、「最小距離 ≤ d」は max|x_i| ≥ a（a = 1/2 - d）と同じ。

つまり P は外側の殻 S = (立方体) − (内側の立方体 [-a, a]^3) にある。球は立方体の内部に収まるので

p(d) = vol(S) − vol(球 ∩ S) = 1 − (2a)^3 − V_out,
V_out = vol(球 ∩ {max|x_i| > a})

となる。V_out は包除原理で求める。6 つのキャップ（|x_i| > a の部分。高さ h = r − a）、
12 個の辺の重なり（たとえば x > a, y > a）、8 個の角（a√3 > r なので、ここでは常に 0）。

### (a) d = 1/4、a = 1/4
内側の立方体の角までの距離は √3/4 < 1/2 なので、内側の立方体は球の中に収まる。
p = 1 − 1/8 − (π/6 − 1/8) = 1 − π/6 ≈ 0.4764012

### (b) d = 1/10、a = 2/5
a < r < a√2 なので、キャップどうしは重ならない。キャップの高さ h = 1/10:
キャップ1つ = π h^2 (3r − h)/3 = 0.014π/3。6 つで 0.028π。
p = 1 − 0.512 − 0.028π = 61/125 − 7π/250 ≈ 0.4000354

### (c) d = 3/20、a = 7/20
a√2 < r < a√3 なので、辺の重なりはあるが、角の重なりは無い。単位球に縮尺を直す（α = a/r = 7/10）。
- キャップ（単位球、h = 0.3）: π·0.09·2.7/3 = 0.081π
- 辺の重なり（単位球、x>α, y>α）:
  E1 = (2/3)atan(√(1−2α²)/α²) + (2/3)α²√(1−2α²) − (2α − 2α³/3)·acos(α/√(1−α²))
  （α=0 では π/3、α=1/√2 では 0 になり、合っている）
  α = 0.7 のとき: √(1−2α²) = √2/10、acos(7/√51) = atan(√2/7) なので E1 ≈ 1.52161e-5

V_out = (1/8)(6·0.081π − 12·E1)
p = 1 − 0.343 − 0.06075π + (3/2)E1
  = 657/1000 − 243π/4000 + atan(10√2/49) + 49√2/1000 − (1757/1000)·atan(√2/7)
  ≈ 0.657 − 0.1908517536 + 0.0000228242 ≈ 0.4661711

答え(a): 1 - pi/6
答え(b): 61/125 - 7*pi/250
答え(c): 657/1000 - 243*pi/4000 + atan(10*sqrt(2)/49) + 49*sqrt(2)/1000 - (1757/1000)*atan(sqrt(2)/7)
