## 考え方

r = 0.6。V1 は線分 OA のまわりのカプセル形（円柱 + 両端の半球）、V2 は線分 AB のまわりのカプセル形。

vol(V1) = pi r^2 * 1 + (4/3) pi r^3 = 0.36 pi + 0.288 pi = 0.648 pi。重心は (0.5, 0, 0)。

A を原点に移した座標 u = x - 1 で共通部分 I = V1 ∩ V2 を見る（u, y はいずれも [-r, r] の範囲に入る）。
- V1: u ≤ 0 なら y^2 + z^2 ≤ r^2、u > 0 なら u^2 + y^2 + z^2 ≤ r^2
- V2: y ≥ 0 なら u^2 + z^2 ≤ r^2、y < 0 なら u^2 + y^2 + z^2 ≤ r^2

(u, y) の 4 つの象限で分けると:
- u>0, y≥0: 球の 1/4（体積 pi r^3/3、重心 (3r/8, 3r/8)）
- u≤0, y<0: 球の 1/4（重心 (-3r/8, -3r/8)）
- u>0, y<0: 球の 1/4（重心 (3r/8, -3r/8)）
- u≤0, y≥0: 直交する 2 本の円柱の共通部分（Steinmetz 立体）の 1/4。体積 4r^3/3、
  u のモーメント = -(1/2)∫(r^2 - z^2)^{3/2} dz = -3 pi r^4/16、y のモーメント = +3 pi r^4/16

vol(I) = pi r^3 + 4r^3/3 = 0.216 pi + 0.288
u モーメント合計 = pi r^4 (2/8 - 1/8 - 3/16) = -pi r^4/16 = -0.0081 pi
y モーメント合計 = pi r^4 (1/8 - 1/8 - 1/8 + 3/16) = pi r^4/16 = 0.0081 pi
x モーメント = vol(I) * 1 - 0.0081 pi = 0.2079 pi + 0.288

W について:
- 体積 = 0.648 pi - 0.216 pi - 0.288 = 0.432 pi - 0.288 ≈ 1.069168
- x モーメント = 0.324 pi - 0.2079 pi - 0.288 = 0.1161 pi - 0.288
- y モーメント = -0.0081 pi

重心 x = (0.1161 pi - 0.288)/(0.432 pi - 0.288) = (129 pi - 320)/(480 pi - 320) ≈ 0.0717744
重心 y = -0.0081 pi/(0.432 pi - 0.288) = -9 pi/(480 pi - 320) ≈ -0.0238007

答え(a): 54*pi/125 - 36/125
答え(b): (129*pi - 320)/(480*pi - 320)
答え(c): -9*pi/(480*pi - 320)
