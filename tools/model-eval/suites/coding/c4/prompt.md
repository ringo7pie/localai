## 問題 C4: 厳密な JSON パーサ

関数 `parse_json(text: str) -> object` を書いてください。RFC 8259 の文法に厳密に従って `text` を 1 つの JSON の値として読み、Python の値に変換します。標準ライブラリの `json` モジュール（`json.loads`、`json.JSONDecoder` など）は使わないでください（使った答えは 0 点）。

### 文法

- `text` 全体が「空白（0 個以上）、値 1 つ、空白（0 個以上）」でなければならない。それ以外（空の文字列、空白だけ、値の前後の余計な文字、値が 2 つ）は `ValueError`。
- 空白は半角スペース、`\t`、`\n`、`\r` の 4 種類だけ。`\f`、`\v`、ノーブレークスペース、先頭の BOM（U+FEFF）は空白ではなく、`ValueError`。
- 値は、オブジェクト、配列、文字列、数、`true`、`false`、`null` のいずれか。トップレベルの値がオブジェクトや配列でなくてもよい（`"abc"` や `42` だけでも正しい）。
- リテラルは `true`、`false`、`null` の小文字だけ。`True`、`NULL`、`nul` は `ValueError`。`NaN`、`Infinity`、`-Infinity` も `ValueError`。
- オブジェクト `{ ... }` は Python の `dict`。キーは必ず文字列。`,` で区切り、末尾の余計な `,`（`{"a":1,}`）や空のメンバー（`{,}`）は `ValueError`。**同じキーが 2 回出てきたら `ValueError`**（エスケープを解いたあとの文字列として同じなら同じキー。`{"a":1,"\u0061":2}` は `ValueError`）。
- 配列 `[ ... ]` は Python の `list`。末尾の余計な `,` や空の要素（`[1,,2]`、`[,1]`）は `ValueError`。
- 文字列は `"` で囲む（`'` は不可）。中で使えるエスケープは `\"` `\\` `\/` `\b` `\f` `\n` `\r` `\t` と `\uXXXX`（16 進 4 桁。大文字小文字どちらも可）だけ。それ以外のエスケープ（`\a`、`\x41`、`\'`、`\U0001F600`、桁の足りない `\u12`）は `ValueError`。
  - 文字列の中にエスケープされていない制御文字（U+0000〜U+001F）があれば `ValueError`。U+007F 以降の文字（日本語や絵文字）はそのまま書いてよい。
  - `\uD83D\uDE00` のように上位サロゲート（U+D800〜U+DBFF）の直後に下位サロゲート（U+DC00〜U+DFFF）の `\u` エスケープが続くときは、合わせて 1 文字（この例では U+1F600）にする。下位サロゲートだけ、上位サロゲートの直後に下位サロゲートのエスケープが続かない、という場合は `ValueError`。`\u0000` は許される（長さ 1 の文字列 `"\x00"`）。
- 数は `-?(0|[1-9][0-9]*)(\.[0-9]+)?([eE][+-]?[0-9]+)?` の形だけ。先頭の `0` に数字が続くもの（`01`）、`+1`、`.5`、`1.`、`1e`、`0x10`、`1_000` は `ValueError`。小数部か指数部があれば Python の `float(その文字列)` と同じ値（`1e400` は `inf`）、どちらも無ければ `int`（桁数に上限はなく、正確な値。`-0` は `int` の `0`）。
- 入れ子の深さは最大 50,000（`[[[[...]]]]` のような深い入れ子でも、正しく値を返すこと）。`text` の長さは最大 1,000,000 文字で、その長さでも十分速く動くこと（たとえば、読み進めるたびに文字列を切り出す（`text = text[1:]`）作りでは間に合わない）。

例:
- `parse_json(' {"a": [1, 2.5, "x\\ny"], "b": {"c": null, "d": true}} ')` → `{"a": [1, 2.5, "x\ny"], "b": {"c": None, "d": True}}`
- `parse_json('"\\u3042\\uD83D\\uDE00"')` → `"あ😀"`
- `parse_json('[1, 2,]')` → `ValueError` を送出
