## 問題 C1: シェル風の単語分割

関数 `split_words(text: str) -> list[str]` を書いてください。

`text` を、次の規則で「単語」のリストに分けます。規則は POSIX シェルの引用の一部を模したものですが、変数展開やワイルドカードの展開はしません（`$`、`*`、`~` などはただの文字です）。

- 区切り: 引用の外にある半角スペース、タブ（`\t`）、改行（`\n`）の 3 種類だけが単語の区切り。連続していても 1 つの区切りとみなし、先頭と末尾の区切りは無視する。それ以外の文字（`\r`、全角スペースなど）は区切りではなく、単語の一部。
- 単一引用符 `'...'`: 中の文字はすべてそのまま単語に入る（バックスラッシュも特別扱いしない）。最初に現れた `'` で閉じる。
- 二重引用符 `"..."`: 中では、バックスラッシュの直後の 1 文字が `"`、`\`、`$`、`` ` `` のいずれかなら、その 1 文字だけを単語に入れる。バックスラッシュの直後が改行なら、その 2 文字を取り除く（行の継続）。それ以外のバックスラッシュはただの文字として残す（`"\n"` の中身は `\` と `n` の 2 文字）。
- 引用の外のバックスラッシュ: 直後が改行なら、その 2 文字を取り除く（行の継続。単語は切れず、区切りにもならない）。それ以外は直後の 1 文字をそのまま単語に入れる（`\ ` は半角スペース、`\'` は `'`、`\#` は `#`）。
- 引用符そのものは単語に入らない。引用された部分と引用の外の部分が隣り合っていれば 1 つの単語になる（`a"b c"d` は `ab cd` という 1 単語）。`''` や `""` だけの単語は空文字列の単語になる。
- コメント: 引用の外の `#` が「単語の先頭」にあるとき、その `#` から行末（次の改行の直前。改行が無ければ文字列の末尾）までを無視する。「単語の先頭」とは、その時点でまだ単語が始まっていない（文字列の先頭か、直前の区切りのあとに、単語の文字も引用符も現れていない）こと。単語の途中の `#`（`a#b`）はただの文字。空の引用のあとの `#`（`''#x`）も単語の途中とみなす。
- 閉じていない引用符、および文字列の末尾にある単独のバックスラッシュには `ValueError` を送出する。
- `text` は最大 100,000 文字。空の文字列、区切りだけの文字列には `[]` を返す。

例（入力は Python の文字列リテラルで書いてある。`\\` はバックスラッシュ 1 文字、`\n` は改行 1 文字）:
- `split_words("a 'b c'  d")` → `["a", "b c", "d"]`
- `split_words('x "y\\"z" # comment\n  w')` → `["x", 'y"z', "w"]`
- `split_words("it's")` → `ValueError` を送出
