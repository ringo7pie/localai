## 問題 C5: 正規表現の部分集合のマッチャ

関数 `regex_search(pattern: str, text: str) -> bool` を書いてください。`pattern` が `text` のどこかの部分文字列（空の部分文字列も含む）に一致すれば `True`、しなければ `False` を返します。標準ライブラリの `re` モジュール（および `sre_parse`、`sre_compile`、`_sre`）は使わないでください（使った答えは 0 点）。

### パターンの文法

- 文字: 普通の文字はその文字そのものに一致する。大文字と小文字は区別する。
- `.`: 改行を含む任意の 1 文字に一致する。
- `\` の直後の 1 文字: その文字そのものに一致する（`\.` は `.`、`\\` は `\`、`\n` は改行ではなく `n`、`\d` は `d`）。パターンの末尾に単独の `\` があれば `ValueError`。
- 文字クラス `[...]`: `[` の直後の `^` は否定（`[^...]` は列挙した文字以外の 1 文字）。中身は左から順に項目として読む。項目を読むときは、まず 1 文字（`\` でエスケープされた文字も 1 文字と数え、エスケープを解いた文字になる）を読み、その直後が `-` で、さらにその次の文字が `]` でなければ範囲 `x-y`（`x` 以上 `y` 以下のコードポイント。`y` もエスケープできる。`x > y` なら `ValueError`）、そうでなければ読んだ 1 文字だけの項目とする。`]` はエスケープしない限り常にクラスを閉じる。`-` は項目の 1 文字目として読まれたとき、または `]` の直前にあるときはただの文字。クラスの中では `.` `*` `+` `?` `|` `(` `)` `^`（先頭以外）`$` はただの文字。項目が 1 つも無い `[]`、`[^]`、閉じていない `[` は `ValueError`。
- `^`: `text` の先頭（位置 0）にだけ一致する幅 0 のアサーション。`$`: `text` の末尾にだけ一致する幅 0 のアサーション（末尾の改行の前には一致しない）。パターンのどこに置いてもよい。
- 量指定子 `*`（0 回以上）、`+`（1 回以上）、`?`（0 回か 1 回）: 直前の要素（1 文字、`.`、エスケープした文字、文字クラス、グループ `(...)`）に付ける。付ける要素が無いとき（パターンの先頭、`(` や `|` の直後）、量指定子を重ねたとき（`a**`、`a*?`）、`^` や `$` に付けたときは `ValueError`。
- グループ `( ... )`: 中身を 1 つの要素にまとめる（キャプチャは要らない）。空のグループ `()` は空文字列に一致する。対応の取れていない `(` や `)` は `ValueError`。
- 選択 `|`: 優先順位は最も低く、左右のどちらかに一致すればよい。空の選択肢（`a|`、`|a`、`(|a)`）は空文字列に一致する。
- 空のパターン `""` はどの `text` にも一致する（`True`）。

### 性能

- `pattern` は最大 100 文字、`text` は最大 10,000 文字。
- バックトラックで指数時間になる作りは不可。`(a|aa)*b` や `(a*)*b` を `"aaaa…a"`（一致しない）と照合する場合や、`a*b` を 5,000 文字の `"aaaa…a"` と照合する場合でも、すぐに答えること（状態集合をたどる方式などを使う）。

例:
- `regex_search("^[a-z]+@[a-z]+\\.[a-z]+$", "foo@bar.com")` → `True`
- `regex_search("(cat|dog)s?$", "I like dogs")` → `True`
- `regex_search("a$", "a\n")` → `False`
