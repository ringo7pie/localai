## AI性能テスト用 数学難問（解答）

### 幾何学的分析と準備

まず、各立体 $V_i$ の形状を分析します。$V_i$ は半径 $r$ の球が線分に沿って移動することでできる「カプセル型」の立体（または円柱の終端部が球でキャップされた形状）です。

1.  **$V_1$ (Path $OA$):** $O(0,0,0)$ から $A(1,0,0)$ への動き。
    $V_1$ は $y^2+z^2 \le r^2$ の円柱形が、両端で半径 $r$ の半球でキャップされた形状です。
    2.  **$V_2$ (Path $AB$):** $A(1,0,0)$ から $B(1,1,0)$ への動き。
    $V_2$ は $x-1=0, z=0$ の直線に沿った動きなので、$(x-1)^2+z^2 \le r^2$ の円柱形が、両端でキャップされた形状です。
    3.  **$V_3$ (Path $BC$):** $B(1,1,0)$ から $C(1,1,1)$ への動き。
    $V_3$ は $x=1, y-1=0$ の直線に沿った動きなので、$(x-1)^2+(y-1)^2 \le r^2$ の円柱形が、両端でキャップされた形状です。

---

### (1) 平面 $y=t$ との共有点の範囲と断面図

平面 $y=t$ が $V_1$ と $V_3$ の両方と共有点を持つ条件を求めます。

#### 1. $V_1$ との共有点条件
$V_1$ は $y^2+z^2 \le r^2$ を中心とした形状です。
$y=t$ で共有点を持つためには、少なくとも $z$ の値が存在する必要があります。
$$t^2 + z^2 \le r^2 \implies z^2 \le r^2 - t^2$$
これが可能である条件は $|t| \le r$ です。

#### 2. $V_3$ との共有点条件
$V_3$ は $(x-1)^2 + (y-1)^2 \le r^2$ を中心とした形状です。
$y=t$ で共有点を持つためには、少なくとも $x$ の値が存在する必要があります。
$$(x-1)^2 + (t-1)^2 \le r^2 \implies (x-1)^2 \le r^2 - (t-1)^2$$
これが可能である条件は $|t-1| \le r$ 、すなわち $1-r \le t \le 1+r$ です。

#### 3. $t$ の範囲
$V_1$ と $V_3$ の両方と共有点を持つためには、上記の2つの条件が同時に満たされる必要があります。
$$t \in [-r, r] \quad \text{かつ} \quad t \in [1-r, 1+r]$$
共通範囲を求めると、
$$t \in [\max(-r, 1-r), \min(r, 1+r)]$$
与えられた条件 $\frac12 < r < 1$ より、
1. $-r < 1-r$ (常に成立)
2. $r < 1+r$ (常に成立)
したがって、$$t \text{ の範囲は } [1-r, r]$$

#### 4. 断面の図示
$y=t$ の断面は、それぞれ $(x, z)$ 平面上の領域となります。

*   **$V_1$ と $y=t$ の共通部分（断面 $C_1$）：**
    $y=t$ を固定すると、 $z^2 \le r^2 - t^2$ となり、 $z$ の範囲は $-\sqrt{r^2-t^2} \le z \le \sqrt{r^2-t^2}$ です。
    また、$V_1$ は $x$ 方向に $r$ から $1+r$ まで伸びているため、 $x$ の範囲は $[-r, 1+r]$ です。
    $$C_1: \{ (x, z) \mid -r \le x \le 1+r, \quad -\sqrt{r^2-t^2} \le z \le \sqrt{r^2-t^2} \}$$
    図形は、幅 $2\sqrt{r^2-t^2}$、長さ $1+2r$ の長方形に近似されます。

*   **$V_3$ と $y=t$ の共通部分（断面 $C_3$）：**
    $y=t$ を固定すると、 $(x-1)^2 \le r^2 - (t-1)^2$ となり、 $x$ の範囲は $1 \pm \sqrt{r^2-(t-1)^2}$ です。
    $V_3$ は $z$ 方向に $[-r, 1+r]$ まで伸びています。
    $$C_3: \{ (x, z) \mid 1-\sqrt{r^2-(t-1)^2} \le x \le 1+\sqrt{r^2-(t-1)^2}, \quad -r \le z \le 1+r \}$$
    図形は、幅 $2\sqrt{r^2-(t-1)^2}$、長さ $1+2r$ の長方形に近似されます。

**（図示：注釈として説明します。実際の図面は手書きとなります。）**
1.  $t$ の値を取る平面 $y=t$ を考える。
2.  $C_1$ は $x$ 軸（$y=0, z=0$）に垂直な断面。長方形であり、幅は $|y=t|$ の距離に依存する。
3.  $C_3$ は $z$ 軸（$x=1, y=1$）に垂直な断面。長方形であり、幅は $|y-1|$ の距離に依存する。

### (2) $V_1 \cap V_3$ が $V_2$ に含まれるための $r$ の条件

点 $(x, y, z)$ が $V_1 \cap V_3$ に含まれるとき、それが必ず $V_2$ に含まれる条件を求めます。

**1. $V_1$ と $V_3$ の共通部分の条件:**
$(x, y, z) \in V_1 \cap V_3$ であるとき、以下の条件が満たされます。
$$\text{(1) } y^2 + z^2 \le r^2$$
$$\text{(2) } (x-1)^2 + (y-1)^2 \le r^2$$

**2. $V_2$ の条件:**
$(x, y, z) \in V_2$ であるためには、
$$\text{(3) } (x-1)^2 + z^2 \le r^2$$

**3. 包含条件の導出:**
$V_1 \cap V_3 \subseteq V_2$ であるためには、(1)と(2)を満たす任意の $(x, y, z)$ が(3)を満たす必要があります。

(1)より、 $z^2 \le r^2 - y^2$.
(2)より、 $(x-1)^2 \le r^2 - (y-1)^2$.

(3)の左辺 $(x-1)^2 + z^2$ の最大値を求め、これが $r^2$ 以下であることを確認します。
$$(x-1)^2 + z^2 \le [r^2 - (y-1)^2] + [r^2 - y^2]$$
$$(x-1)^2 + z^2 \le 2r^2 - (y^2 - 2y + 1) - y^2$$
$$(x-1)^2 + z^2 \le 2r^2 - 2y^2 + 2y - 1$$

この最大値が $r^2$ 以下でなければなりません。
$$2r^2 - 2y^2 + 2y - 1 \le r^2$$
$$r^2 - 1 + 2y - 2y^2 \le 0$$
$$2y^2 - 2y + (1 - r^2) \ge 0$$

この条件は、$(x, y, z)$ が存在するすべての $y$ の範囲（つまり $V_1 \cap V_3$ の $y$ 座標の射影）に対して成立する必要があります。
$V_1 \cap V_3$ の $y$ 座標の射影は、(1)と(2)より $|y| \le r$ かつ $|y-1| \le r$ を満たす範囲、すなわち $y \in [1-r, r]$ です。

$f(y) = 2y^2 - 2y + (1 - r^2)$ を $y \in [1-r, r]$ で最小化し、その最小値が 0 以上であることを求めます。
$f(y)$ は下に凸な放物線であり、頂点の $y$ 座標は $y = -(-2)/(2 \cdot 2) = 1/2$ です。
$r > 1/2$ より、頂点 $y=1/2$ は常に区間 $[1-r, r]$ に含まれます。
最小値は頂点でとるので、
$$f_{min} = f(1/2) = 2(1/4) - 2(1/2) + (1 - r^2) = 1/2 - 1 + 1 - r^2 = 1/2 - r^2$$

$V_1 \cap V_3 \subseteq V_2$ の条件は $f_{min} \ge 0$ です。
$$\frac{1}{2} - r^2 \ge 0 \implies r^2 \le \frac{1}{2}$$
$$r \le \frac{1}{\sqrt{2}}$$

与えられた条件 $\frac{1}{2} < r < 1$ を考慮すると、必要な条件は、
$$\frac{1}{2} < r \le \frac{1}{\sqrt{2}}$$

### (3) $V_1$ の体積

$V_1$ は、長さ $L=1$ の円柱状のセグメントと、両端の半径 $r$ の半球が結合したカプセル型立体です。
体積 $V_1$ は、円柱の体積 $V_{cyl}$ と、二つの半球（球全体）の体積 $V_{sph}$ の合計として計算できます。
$$V_1 = V_{cyl} + V_{sph}$$
$$V_{cyl} = (\text{断面積}) \times (\text{長さ}) = \pi r^2 \cdot 1$$
$$V_{sph} = \frac{4}{3} \pi r^3$$
$$V_1 = \pi r^2 + \frac{4}{3} \pi r^3 = \pi r^2 \left( 1 + \frac{4}{3} r \right)$$

---

### (4) $V_1 \cup V_2 \cup V_3$ の体積

(2) の条件 $r \le 1/\sqrt{2}$ を満たすとき、体積は包含排除の原理 (PIE) を用いて計算します。

$$V_{\text{total}} = (V_1 + V_2 + V_3) - (V_1 \cap V_2) - (V_1 \cap V_3) - (V_2 \cap V_3) + (V_1 \cap V_2 \cap V_3)$$

対称性より、$V_1 = V_2 = V_3$ であり、$V_{12} = V_{13} = V_{23}$ です。
$$V_{\text{total}} = 3 V_1 - 3 V_{12} + V_{123}$$
ただし、$V_{12} = V_1 \cap V_2$ および $V_{123} = V_1 \cap V_2 \cap V_3$ です。

**1. $V_1$ の体積:**
$$V_1 = \pi r^2 \left( 1 + \frac{4}{3} r \right)$$

**2. 共通部分の体積 ( $V_{12}$ および $V_{123}$):**
$V_1, V_2, V_3$ の共通部分は、互いに直交する三つの軸に沿ったカプセル体の交差体積となり、これらは解析的に非常に複雑です。ここでは、幾何学的な複雑さにより、体積を具体的な式で導出することは困難であり、一般的な構造を維持したまま記述します。

*   $V_{12} = V_1 \cap V_2$: $V_1$ の軸 (x軸) と $V_2$ の軸 (y軸) が $A(1, 0, 0)$ で交わる交差体の体積。
*   $V_{123} = V_1 \cap V_2 \cap V_3$: 三軸が $A(1, 0, 0)$ の近くで交わる交差体の体積。

体積を $V_{12}(r)$ および $V_{123}(r)$ と定義すると、求める体積は：
$$V_1 \cup V_2 \cup V_3 = 3 \pi r^2 \left( 1 + \frac{4}{3} r \right) - 3 V_{12}(r) + V_{123}(r)$$
