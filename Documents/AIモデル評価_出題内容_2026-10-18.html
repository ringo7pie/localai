## 問題 H1: 整数座標の 3 次元凸包

関数 `hull3d(points: list[tuple[int, int, int]]) -> tuple[int, int, int]` を書いてください。3 次元空間の整数座標の点の集まりの凸包（すべての点を含む最小の凸多面体）について、`(volume6, n_faces, n_vertices)` を返します。

- `volume6`: 凸包の体積の 6 倍（整数になる）。
- `n_faces`: 凸包の面の数。同じ平面にある三角形はまとめて 1 つの面（多角形）と数える。たとえば立方体の面は 6。
- `n_vertices`: 凸包の頂点（角）の数。辺の途中や面の内側、凸包の内部にある点は頂点ではない。同じ座標の点が何度あっても 1 つと数える。

### 入力と誤り

- 座標は絶対値が 10**6 以下の整数。点は最大 3,000 個。同じ座標の点が重なっていてもよい。
- 異なる点が 4 つ未満のとき、またはすべての点が 1 つの平面上（直線上も含む）にあるときは `ValueError`。
- 浮動小数点数で計算すると、同じ平面にあるかの判定を誤る。整数だけで計算してください。

### 性能

- 3,000 点（すべての点が凸包の表面にある場合や、格子状に並んで同じ平面に多くの点がある場合も含む）で、1 回の呼び出しが 1 秒程度で終わること。O(n**4) の総当たりや、点を追加するたびにすべての面を調べ直す作りでは時間切れになることがある。

例:
- `hull3d([(0, 0, 0), (1, 0, 0), (0, 1, 0), (0, 0, 1)])` → `(1, 4, 4)`
- 立方体の 8 つの角 `[(x, y, z) for x in (0, 1) for y in (0, 1) for z in (0, 1)]` → `(6, 6, 8)`
- 0〜2 の格子点 27 個（各辺の中点・各面の中心・中心を含む）→ `(48, 6, 8)`

H2 最短で、辞書順が最小の編集スクリプト

2 つの文章（行の並び）の違いを「残す・消す・足す」の操作の列で表すとき、消す・足すの数が最も少なく、しかも決まった順番で最も前に来るものを求める問題です。

やること

関数 shortest_edit_script を書きます。行の並び a を b に変える操作の列（編集スクリプト）のうち、消す・足すの合計が最小のものを返します。最小のものが複数あるときは、操作の記号を「残す < 消す < 足す」の順として、先頭から比べて最も前に来るものを返します。標準ライブラリの difflib を使うと 0 点です。

具体例

入力
shortest_edit_script(["a", "b", "c"], ["a", "c"])
→
期待する答え
[("=", 0, 0), ("-", 1), ("=", 2, 1)]

b を消すだけです。= は残す、- は消す、+ は足す、数は読んでいる位置です。

入力
shortest_edit_script(["a", "b"], ["b", "a"])
→
期待する答え
[("-", 0), ("=", 1, 0), ("+", 1)]

「先に b を足して最後の b を消す」も同じく編集 2 回ですが、1 つ目の操作で「消す」が「足す」より前なので、こちらを返します。

入力
shortest_edit_script(["a", "x", "a"], ["a"])
→
期待する答え
[("=", 0, 0), ("-", 1), ("-", 2)]

最初の a を残しても、最後の a を残しても編集は 2 回です。残せるときは先に残す方を返します。

何が難しいか

  • 最短の答えは何通りもあることがあり、その中から決まった 1 つを選ぶ必要があります。最短を求めるだけの方法では、別の最短を返してしまいます。
  • 「残せるなら残す」を素直に先にやると、全体では最短でなくなる入力があります。最短を保ったまま順番の決まりを守る工夫が要ります。
  • 長さ 5,000 の並びを 1 秒程度で処理します。5,000 × 5,000 の表を作る素直な方法は間に合わず、違いの数に比例する時間で解く方法（Myers の方法）が要ります。

何の力を見るか

定番のアルゴリズム（差分を求める Myers の方法）を知っていて、それを「最短の中で辞書順が最小」という追加の条件に合わせて、正しく作り変える力を見ます。

### 編集スクリプト

- `a` と `b` を先頭から同時に読み進める操作の並び。操作は次の 3 種類のタプル。
  - `("=", i, j)`: `a[i]` を残す（`a[i] == b[j]` のときだけ使える）。`a` と `b` を 1 つずつ進める。
  - `("-", i)`: `a[i]` を消す。`a` を 1 つ進める。
  - `("+", j)`: `b[j]` を足す。`b` を 1 つ進める。
- 最後には `a` と `b` を両方とも読み終える。`i` と `j` は読んでいる位置そのもの（0 始まり）。
- 編集の数は `"-"` と `"+"` の操作の合計。これが最小のスクリプトを「最短」と呼ぶ。最短のスクリプトはどれも操作の数が同じになる。

### どれを返すか

- 最短のスクリプトが複数あるときは、操作の記号の並びを先頭から比べ、記号の順を `"=" < "-" < "+"` とした辞書順で最小のものを返す（同じ位置で比べて、残せるなら残す、そうでなければ消す方を足す方より先に選ぶ）。

### 性能

- `a` と `b` の長さはそれぞれ最大 5,000。ただし編集の数が 100 を超えるのは、長さの合計が 600 以下のときだけ。最大の入力でも 1 秒程度で答えること。長さの積に比例する表を作る作り（5,000 × 5,000）は時間切れになる。

例:
- `shortest_edit_script(["a", "b", "c"], ["a", "c"])` → `[("=", 0, 0), ("-", 1), ("=", 2, 1)]`
- `shortest_edit_script(["x"], ["y"])` → `[("-", 0), ("+", 0)]`
- `shortest_edit_script(["a", "b"], ["b", "a"])` → `[("-", 0), ("=", 1, 0), ("+", 1)]`（`[("+", 0), ("=", 0, 1), ("-", 1)]` も最短だが、1 つ目の記号で `"-"` が先）
- `shortest_edit_script(["a", "x", "a"], ["a"])` → `[("=", 0, 0), ("-", 1), ("-", 2)]`（`[("-", 0), ("-", 1), ("=", 2, 0)]` も最短だが、1 つ目の記号で `"="` が先）
- `shortest_edit_script([], ["p", "q"])` → `[("+", 0), ("+", 1)]`

## 問題 H3: 小さな関数型言語の型推論（Hindley–Milner）

関数 `infer(src: str) -> str` を書いてください。下の小さな言語の式 `src` の型を Hindley–Milner の型推論（let 多相あり）で求め、決まった書き方の文字列で返します。

### 字句

- 空白（スペース・タブ・改行）は字句の区切り。
- 整数: `0`〜`9` の並び（負の数の字句は無い。`-` はいつも引き算）。
- 名前: 英小文字か `_` で始まり、英字・数字・`_`・`'` が続く。ただし予約語 `fun` `let` `rec` `in` `if` `then` `else` `true` `false` は名前にならない。
- 記号: `->` `::` `(` `)` `,` `+` `-` `*` `=` `<` `[` `]`。`[` の直後には `]` しか書けない（`[]` で空のリスト）。
- それ以外の文字は構文の誤り。

### 構文（優先順位の低い順）

1. `fun x1 x2 ... -> e`（引数 1 つ以上）、`let x = e1 in e2`、`let f x1 ... = e1 in e2`（`let f = fun x1 ... -> e1 in e2` と同じ）、`let rec f x1 ... = e1 in e2`（引数 1 つ以上）、`if e1 then e2 else e3`。どれも右へできるだけ長く伸びる。これら 4 つは、式全体・括弧の中（組の各要素も含む）・`->` の後・let の `=` の後・`in` `then` `else` の後にだけ書ける（関数の引数や演算子の右に書くには括弧が要る。括弧なしで書いたら構文の誤り）。
2. `e1 = e2`、`e1 < e2`（左結合）
3. `e1 :: e2`（右結合）
4. `e1 + e2`、`e1 - e2`（左結合）
5. `e1 * e2`（左結合）
6. 関数の適用 `e1 e2`（並べて書く。左結合。`f x y` は `(f x) y`）
7. 整数、`true`、`false`、名前、`[]`、`( e )`、組 `( e1 , e2 )`（2 つ組だけ）

### 型の規則

- 整数は `int`、`true` と `false` は `bool`、`[]` は `'a list`、組は `t1 * t2`。
- `+` `-` `*` は `int -> int -> int`、`<` は `int -> int -> bool`、`=` は `'a -> 'a -> bool`（両辺が同じ型）、`::` は `'a -> 'a list -> 'a list`。
- `if` の条件は `bool`、2 つの枝は同じ型。
- 最初から使える名前（`let` や `fun` で同じ名前を作れば隠れる）: `fst : 'a * 'b -> 'a`、`snd : 'a * 'b -> 'b`、`hd : 'a list -> 'a`、`tl : 'a list -> 'a list`、`null : 'a list -> bool`。
- `let` で束縛した名前は多相（その時点の環境に現れない型変数を一般化する）。`fun` の引数は単相。`let rec` の関数は、自分の本体の中では単相、`in` の後では多相。

### 答えの型の書き方

- 基本の型は `int`・`bool`、型変数は `'a` `'b` …。型の中を左から右へ読んで最初に現れた順に `'a`, `'b`, …, `'z`, `'a1`, `'b1`, … と名前を付け直す。
- `->` は右結合で最も弱い。`*` は `->` より強い。`list` は後置で最も強い。必要なところにだけ括弧を付ける（`->` の左の関数型、`*` の両側の関数型と組の型、`list` の前の関数型と組の型）。
- 区切りは `->` と `*` の前後に空白 1 つ、`list` の前に空白 1 つ。例: `('a -> 'b) -> 'a list -> 'b list`、`(int * bool) list`、`int * (bool * 'a)`、`('a -> 'a) * int`。

### 誤り

- 構文の誤りは `SyntaxError`、定義されていない名前は `NameError`、型が合わない（自分を含む型になる場合も）ときは `TypeError` を投げる。
- 構文は式全体を読んでから型を調べる（構文の誤りがあれば、ほかの誤りより先に `SyntaxError`）。

### 性能

- `src` は最大 20,000 文字、括弧や `let` の入れ子は最大 300 段。どれも 1 秒程度で答えること（入れ子が深くても `RecursionError` を出さないこと）。

例:
- `infer("fun x -> x")` → `"'a -> 'a"`
- `infer("let id = fun x -> x in (id 1, id true)")` → `"int * bool"`
- `infer("fun f -> (f 1, f true)")` → `TypeError`
- `infer("fun f g x -> f (g x)")` → `"('a -> 'b) -> ('c -> 'a) -> 'c -> 'b"`
- `infer("let rec len l = if null l then 0 else 1 + len (tl l) in len")` → `"'a list -> int"`
- `infer("1 + y")` → `NameError`

## 問題 H4: 分母に上限のある最良の有理近似

関数 `best_rational(num: int, den: int, max_den: int, side: int = 0) -> tuple[int, int]` を書いてください。有理数 `x = num / den` を、分母が `max_den` 以下の分数 `p / q`（`p` は整数、`q` は `1 <= q <= max_den` の整数）で近似し、`(p, q)` を返します。標準ライブラリの `fractions` モジュールと `decimal` モジュールは使わないでください（使った答えは 0 点）。浮動小数点数で計算すると誤差で誤ります。整数だけで計算してください。

### 選び方

- `side == 0`: `|x - p/q|` が最小の分数。最小のものが複数あるときは、`q` が小さい方、それも同じなら `p` が小さい方（数として小さい方。`-1 < 0`）を返す。
- `side == -1`: `p/q <= x` を満たす分数のうち、値が最大のもの。
- `side == 1`: `p/q >= x` を満たす分数のうち、値が最小のもの。
- 返す分数は既約にする（`q >= 1` かつ `p` と `q` の最大公約数が 1。`p == 0` なら `(0, 1)`）。同じ値の分数は 1 つと数える。
- `x` 自身の既約分数の分母が `max_den` 以下なら、どの `side` でもその既約分数を返す。

### 入力と誤り

- `num` と `den` は任意の大きさの整数（負でもよい。`den` が負なら `x` は `num / den` の値どおり）。

次の 2 つの関数を書いてください。標準ライブラリの `re` モジュール（および `sre_parse`、`sre_compile`、`_sre`）は使わないでください（使った答えは 0 点）。

- `min_dfa_size(pattern: str, alphabet: str) -> int`: 文字の集合 `alphabet` の上で、`pattern` に**全体が**一致する文字列の集合（言語）を受理する、状態数が最小の**完全な** DFA の状態数を返す。完全とは、どの状態にも `alphabet` のすべての文字の遷移があること（受理できなくなった後の「死んだ状態」も 1 つと数える）。言い換えると、`alphabet` 上の文字列を「後ろに何を付けたら受理されるか」で分けたときの類の数。

### alphabet

- 1〜8 文字の、互いに異なる文字の並び。空、または同じ文字が 2 度あれば `ValueError`。
- 言語は `alphabet` の文字だけからなる文字列の集合として考える。

### パターンの文法

- 普通の文字: その文字そのものに一致する。`alphabet` に無い文字は、どの文字列にも現れないので一致しない（その部分の言語は空）。`^` と `$` も普通の文字。
- `.`: `alphabet` の任意の 1 文字に一致する。
- `\` の直後の 1 文字: その文字そのものに一致する（`\.` は `.`、`\\` は `\`、`\n` は `n`）。パターンの末尾に単独の `\` があれば `ValueError`。
- 文字クラス `[...]`: `[` の直後の `^` は否定（`[^...]` は列挙した文字以外の、`alphabet` の 1 文字）。中身は左から順に項目として読む。項目を読むときは、まず 1 文字（`\` でエスケープされた文字も 1 文字と数え、エスケープを解いた文字になる）を読み、その直後が `-` で、さらにその次の文字が `]` でなければ範囲 `x-y`（`x` 以上 `y` 以下のコードポイント。`y` もエスケープできる。`x > y` なら `ValueError`）、そうでなければ読んだ 1 文字だけの項目とする。`]` はエスケープしない限り常にクラスを閉じる。`-` は項目の 1 文字目として読まれたとき、または `]` の直前にあるときはただの文字。クラスの中では `.` `*` `+` `?` `|` `(` `)` `^`（先頭以外）`$` はただの文字。項目が 1 つも無い `[]`、`[^]`、閉じていない `[` は `ValueError`。`alphabet` に無い文字は列挙しても一致しない。
- 量指定子 `*`（0 回以上）、`+`（1 回以上）、`?`（0 回か 1 回）: 直前の要素（1 文字、`.`、エスケープした文字、文字クラス、グループ）に付ける。付ける要素が無いとき（パターンの先頭、`(` や `|` の直後）、量指定子を重ねたとき（`a**`、`a*?`）は `ValueError`。
- グループ `( ... )`: 中身を 1 つの要素にまとめる。空のグループ `()` は空文字列に一致する。対応の取れていない `(` や `)` は `ValueError`。
- 選択 `|`: 優先順位は最も低い。空の選択肢（`a|`、`|a`、`(|a)`）は空文字列に一致する。
- 空のパターン `""` は空文字列だけに一致する。

### 性能

- パターンは最大 100 文字。最小 DFA の状態数が数千になる場合も、1 回の呼び出しが 1 秒程度で終わること。文字列を短い順に全部試す作りは時間切れになる。
