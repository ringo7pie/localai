# 3D 問題（線分を動く球の通過立体）を解かせた AI モデルの一覧

作成 2026-10-08。問題は `TestData/数学難問-三次元空間-TEST.md`（O=(0,0,0)、A=(1,0,0)、B=(1,1,0)、C=(1,1,1)、
1/2 < r < 1。線分 OA・AB・BC を半径 r の球が動いてできる立体 V1・V2・V3）。

## 正解（モンテカルロで検算済み）

| 小問 | 正解 |
|---|---|
| (1) | 1−r ≤ t ≤ r。断面は (x,z) 平面で、V1 は線分 (0,0)–(1,0) を半径 √(r²−t²) で太らせたスタジアム形、V3 は線分 (1,0)–(1,1) を半径 √(r²−(1−t)²) で太らせたスタジアム形 |
| (2) | 1/2 < r ≤ √2/2（= 1/√2） |
| (3) | πr² + (4/3)πr³ |
| (4) | 3πr² + (2π − 8/3)r³（r=0.6 で 4.1741、モンテカルロ 4.1747±0.0021） |

### 各モデルの答えの要点

- **qwen3.8:27b（09-20）**: 全問正解。V1∩V2 = (π+4/3)r³ を正しく出し、包除原理で V1∩V3 の項が打ち消されることも説明した。
- **qwen3.8:27b（09-28）**: (1)〜(3) 正解。(4) は途中で 3πr²+2πr³−(8/3)r³（正しい）まで出したあと、書き換えで
  3πr²−2πr³+(4/3)r³ = πr²(3−2r)+(4/3)r³ と計算を誤り、それを答えにした。
- **gemma4:e4b**: (1) のみ正解。(2) は r ≥ √2/2（不等号の向きが逆）。(3)(4) は「複雑な積分が必要」として答えを出さなかった。
- **gemma4:e4b（10-08、md 版を Ollama API で 3 回）**: 3 回とも 2 分前後で答えを返し、(1)(3) は 3 回とも正解、(2) は 3 回中 2 回正解、
  (4) は 3 回とも誤り。1 回目は (2) で「V1∩V3 は空集合なので常に成り立つ」と誤り（実際は (1,1/2,0) などが共通部分にある）、
  (1) の断面も「2 つの円の共通部分」と誤った。(4) は V1∩V2 を正しく求められず、1 回目と 3 回目は V1∩V2 などを記号のまま残し、
  2 回目は重なりを根拠なく 2πr³/3 と置いて 3πr²+(8/3)πr³ とした。どの回も「大学院レベルで解けない」などと述べて (4) を
  打ち切っている。出力は `tools/qwen-model-bench/fixtures/3d-gemma4-e4b/`（run1〜3 の本文と thinking）。
- **gemma4:31b-it-qat**: 全問正解。ただし 1 時間かかった（5.2 tok/s）。
- **gemma4:31b-ctx32k**: 全問正解。V1∩V2 を「スタインメッツ立体の 1/4 と球の 3/4」と正しく分けた。最短（7 分 21 秒）で全問正解。
- **qwen3.8-flash-next:IQ4_XS**: 全問正解（(4) は 3πr²+2πr³−(8/3)r³ の形）。Modelfile の既定 temperature 1.0 / top_p 0.95 / top_k 20。
- **Strata 汎用版 RVN IQ3_S**: 思考が終わらない（下の内訳）。同じ文を繰り返すループではなく、同じ式の書き直しと
  問題の前提を疑う脇道が続く型。
- **Strata 公式版 IQ3_XXS**: 予算なしで 2 回とも収束して全問正解。

  strata-official:IQ3_XXS（12 分 54 秒〜15 分 4 秒）。
- 答えを出せなかったのは Strata 汎用版 RVN IQ3_S（予算なしの 9 本すべて）。予算で打ち切れば答えは返るが、正答は揺れる。
- 同じ Qwen3.8-Flash-Next 系でも、非 abliterated の IQ4_XS（Ollama）と公式 IQ3_XXS（Strata）は全問正解し、
  abliterated の RVN IQ3_S だけが収束しなかった（原因が abliteration か量子化かは切り分けていない）。

  Modelfile の値は確認していない。

  md 版（459 トークン）。中身は同じ。

  `tools/strata/README.md` の「汎用版で thinking が終わらないとき」と「公式版（非 abliterated）IQ3_XXS」。Strata の画面
